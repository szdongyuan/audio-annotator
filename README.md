# 音频标注 · Audio Annotator

0.4.0 · Windows x64 本地音频频谱标注工作区。支持 WAV、FLAC、MP3、1–6 通道、双文件对比、STFT/梅尔频谱、统一框选与右键操作、三层独立分类与备注、文件夹批量导入、非破坏性频段试听和屏蔽、自动保存及 JSON/ZIP 分享。原始音频保持只读。

新建项目直接使用本机作者，无需注册；本机与 NAS 使用相同的作者隔离项目。同事打开 `collaboration.json` 自动获得自己的本机作者，也可选择项目账号。各作者的相同区域分别保留，他人内容只读；音量、屏蔽与视图只存本机。所有作者都可追加音频，他人新增文件从“协作 → 更新音频列表”主动载入；“从我的列表隐藏”只改变个人显示。保存先落本机，再发布本人的标注。无需服务器，目录权限由 NAS 管理。

默认“暂存编辑”同时显示和播放屏蔽后的结果。激活框内拖动移动，框外首次操作取消激活，再次拖动新建；悬浮条可直接播放和分类。普通播放自动使用激活选区，右键白色虚线定位后可“从此处播放”。两侧文件独立选择，设置浮窗可点击外部关闭。分享默认包含全部原音频；“另存我的项目副本…”复制经校验音频，保留本人标注和私人操作，生成新项目。

新项目使用共享格式 2；旧普通格式 2 和旧协作格式 1 可显式打开，无自动迁移。JSON 分享在创建项目前要求关联并校验原音频；ZIP 可直接导入。Delete 屏蔽选区，对象删除使用明确菜单项。

安装包位于 `target/release/bundle/nsis/`。本版没有代码签名证书；安装包未签名。NSIS 包内含 WebView2 离线安装程序，普通本地项目的标注、保存、播放和分享不需要网络；NAS 同步需要共享目录可达。实际验证范围及未测环境以本版验收记录为准。

开发环境需要 Windows x64、Node.js 22.12+、Rust 1.91+ MSVC、Visual Studio C++ Build Tools 与 Windows SDK。首次准备依赖/驱动和打包 WebView2 时需要联网。

```powershell
npm.cmd ci
npm.cmd run fixtures
npm.cmd run tauri -- dev
```

项目自身的授权条款尚未指定；第三方许可证不等于给本项目指定许可证。
