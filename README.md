# 音频标注 · Audio Annotator

0.3.0 · Windows x64 本地音频频谱标注工作区。支持 WAV、FLAC、MP3、1–6 通道、双文件对比、STFT/梅尔频谱、统一框选与右键操作、三层独立分类与备注、文件夹批量导入、非破坏性频段试听和屏蔽、自动保存及 JSON/ZIP 分享。原始音频保持只读。

新增 NAS 目录协作：从普通项目“创建协作副本…”到空目录，同事打开 `collaboration.json` 即可访客查看，也可注册本项目账号。只共享各作者自己的标注、类别与三层备注；他人内容只读，相同位置分别保留。音量、屏蔽与视图保存在本机身份工作区。协作媒体目录固定，调整前先另存个人副本。“导出我的标注 / 项目包”仅包含本人；本机保存、待同步和共享冲突分别显示。无需服务器，账号隔离依赖可信目录，实际文件权限由 NAS 管理。

默认“暂存编辑”同时显示和播放屏蔽后的结果。激活框内拖动移动，框外首次操作取消激活，再次拖动新建；悬浮条可直接播放和分类。普通播放自动使用激活选区，右键白色虚线定位后可“从此处播放”。两侧文件独立选择，设置浮窗可点击外部关闭。分享默认包含全部原音频；“另存项目副本…”继续引用原音频。

普通项目及分享文件使用格式 2，协作清单使用独立格式 1；无自动迁移。Delete 屏蔽选区，对象删除使用明确菜单项。

安装包位于 `target/release/bundle/nsis/`。本版没有代码签名证书；安装包未签名。NSIS 包内含 WebView2 离线安装程序，普通本地项目的标注、保存、播放和分享不需要网络；NAS 同步需要共享目录可达。没有声称在全新 Windows 系统、物理 SMB/NAS 或 exFAT 实体设备上完成验证。

开发环境需要 Windows x64、Node.js 22.12+、Rust 1.91+ MSVC、Visual Studio C++ Build Tools 与 Windows SDK。首次准备依赖/驱动和打包 WebView2 时需要联网。

```powershell
npm.cmd ci
npm.cmd run fixtures
npm.cmd run tauri -- dev
```
