# 0.7.6 测试版

- 修复展开其他文件夹后只显示数量、不显示其中音频的问题。普通目录浏览与导入目标分开；搜索和批量操作保留目录范围。
- 修复跨目录进入多选后 Shift 连选遗漏中间音频的问题。
- 频谱显示前只检查当前音频，同一音频的多个通道共享尚未完成的检查。保留源文件变化校验、原有 STFT/梅尔参数、频率坐标、插值和颜色计算。
- 播放、示例预览和导入取消等命令等待项目锁时改在后台执行，避免把原生窗口主线程一起阻塞。

独立的 876 条音频 NAS 测试项目中，24 次已访问音频切换的完整频谱显示中位耗时由 1975.9 ms 降至 189.8 ms，P95 由 2244.6 ms 降至 257.1 ms。两种测试音频在本地和 NAS 的最终画布像素哈希均与旧版一致。首次打开、其他设备和真实项目的耗时可能不同，详见 [验证记录](verification-0.7.6.md)。

现有项目、标注和共享目录格式不变，无需迁移。安装前保存并关闭所有音频标注窗口，再运行安装包。此包包含此前示例音频库及目录导航修复。

本次修复了可复现的窗口主线程等待项目锁问题；无法仅凭系统挂起日志证明它是此前永久无响应的唯一原因。没有因未复现的增益问题而改动增益计算。文件夹关联回收站音频时仍保留原删除限制。
