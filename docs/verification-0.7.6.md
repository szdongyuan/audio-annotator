# 0.7.6 响应与频谱切换验证

## 范围与原因

普通目录树曾复用选中文件夹的筛选，导致其他已展开目录有数量却无音频行。现在普通浏览显示全部展开目录，导入目标保持不变；显式筛选与批量操作保持范围，跨范围进入多选后重新建立 Shift 锚点。

频谱切换的校验路径曾逐个检查整个项目的源文件，即使已有可复用的频谱数据也要等待。本次新增可选的媒体 ID 范围，并仅共享同一项目、同一源身份尚未结束的检查；检查完成后不缓存其结论。后台全库状态轮询仍保留。原有源文件变化、运行实例、算法版本及暂存编辑有效性检查不变，未改变频谱采样或绘图数学。

本地 Tauri/Wry 源码确认普通同步命令在 Windows WebView 回调线程直接执行。播放重置等命令会获取项目锁，后台持锁保存或 NAS 目录写入可阻塞该线程。12 个相关命令改为异步入口与后台阻塞任务，所有原有权限及身份检查和修改仍位于原锁范围内。用户安装版存在 Windows AppHangB1 记录，但该记录没有线程转储，不能据此确认历史挂起的唯一原因。

## 测量方法与结果

使用独立本地与 NAS 项目、隔离的应用身份目录。每个项目通过真实导入建立 876 条记录：两条 8.85 秒、48 kHz、单通道 WAV，另外 874 条短 WAV 用于还原目录规模。两个选中音频使用不同频率，避免错误显示同一幅图也通过检查。

实际 Windows Tauri/WebDriver 点击音频，计时从 pointerdown 开始，到校验完成、全部频谱块绘制完成且再经过两个动画帧。每个项目记录 2 次首次切换和 24 次后续切换；下面只比较后续切换，不声称清空操作系统文件缓存。测量期间不运行构建或测试负载。

| 位置 | 旧版中位 ms | 修复后中位 ms | 旧版 P95 ms | 修复后 P95 ms |
| --- | ---: | ---: | ---: | ---: |
| 本地 | 218.5 | 195.9 | 324.7 | 240.8 |
| NAS | 1975.9 | 189.8 | 2244.6 | 257.1 |

同一项目及音频在每次切换后的完整 RGBA 画布均计算 SHA-256。两种音频、本地及 NAS 的全部结果在各自运行内一致，跨旧版与修复版逐一一致；分析设置和视口尺寸/DPR相同。原始记录保存在本机 `.test-output/switch-performance/baseline-epFjsj/report.json` 和 `candidate-09sQvL/report.json`，汇总见 [switch-summary.json](evidence/2026-10-28-v0.7.6/switch-summary.json)。没有使用低分辨率预览或缩小窗口、增大 hop 来提速。

初始测量脚本曾因直接导入数量上限、字符串引号、不可覆盖的 invoke 函数以及 Selenium 遮罩点击方式失败；失败记录保留。最终脚本以每批不超过 128 条真实导入，并观察 fetch（非阻塞地克隆响应取得计数），在正式测量前验证仪器工作。计时数据在后续交互检查前落盘。

## 原生窗口与组合交互

独立原生线程持有项目锁 1500 ms，通过真实命令分发测试：模拟原同步调用的负对照使主线程心跳延迟 1500.5 ms；12 个修复入口在仍等待锁时均能完成主线程心跳，延迟 83.7–99.5 ms。正常结果和旧身份拒绝保持有效。该负对照复现原调用方式，不是历史挂起现场。锁释放由独立定时线程完成，测试钩子只在 e2e 功能中编译。

实际窗口组合测试通过兄弟目录展开、跨目录上下切换和焦点滚动，以及六轮无选区增益点击、禁用菜单、Escape/外部点击关闭、音频切换、监听菜单与下拉、创建/清除选区。指针、键盘和动画帧继续推进，没有遗留 inert 根节点或意外增益编辑。回收站目录提示、目录归属和原音频哈希保持。原始记录为 `.test-output/native-responsiveness/desktop-kCOKQ1/report.json` 和 `.test-output/folder-navigation/desktop-EaH7qy/report.json`。

性能及窗口测试使用最终功能代码的 E2E 程序；之后仅将发布版本标识从 0.7.5 改为 0.7.6。测试程序 SHA-256 为 `7775dff8759ace62fb4ed6aaafb641bf2dcd970bd584f18c77aea0c4fdaa381a`，保存在本机 `.test-output/responsiveness/e2e-executable/`。

## 最终回归

- 0.7.6 前端：87 个文件、779 项测试通过（单 worker，避免构建负载影响已有导入计时测试）；日志 `.test-output/responsiveness-frontend-final.log`。
- 0.7.6 原生后端：release + e2e 的全部 99 项单元测试通过，包含源文件状态范围、运行实例变化和项目锁等待；日志 `.test-output/responsiveness-native-final.log`。
- 桌面阶段注册与离线资源检查 2 项通过；新增原生响应测试加入顺序桌面测试入口，876 条切换基准保留为显式运行的性能测试。
- 功能及质量独立审查通过。审查发现的跨目录 Shift 锚点问题已用三行音频的回归测试修复；最终全量检查覆盖修复后的代码。

未重复全部历史桌面阶段、真实多电脑并发或一万条导入压力测试，没有改动用户项目或执行覆盖安装。
