# 项目示例音频（0.7.5）

右侧“示例”保存当前项目的参考音频，如 OK1、NG1、转动异常。示例不会增加普通音频列表、目录或标注数量；换到另一个项目需要重新导入。

“我的示例”只对当前 UUID 身份可见，保存在本机的当前项目私人目录。“共享示例”的记录和原始音频保存在项目文件夹的 `examples/<作者 UUID>/`，打开同一项目的同事可以查看、播放和复制。共享记录显示创建者，只有创建者可以重命名或移除。复制会建立独立记录，移除其中一份不会删除另一份。相同昵称或名称不代表同一个身份或示例。

点击加号导入 WAV、FLAC 或 MP3，可逐条修改名称并选择保存到我的或共享示例。一次最多选择 32 个文件；每行保留成功或失败结果，失败后可核对重试，已导入条目保留。名称限 1–128 个非控制字符，不可全为空白；同名示例可以共存。每个身份在每个范围最多保存 1000 条。也可以选中普通音频后点击“添加当前音频为示例”。搜索框按名称筛选，行右键或更多菜单提供重命名、移除、复制及查看频谱。

导入复制原音频字节到示例专用目录，成功后无需保留外部来源路径，不会重命名、移动或改写来源。共享原音由项目文件夹携带，私人原音保存在本机。请在“已导入”后再处理外部来源。缺失、损坏或被改写的示例会提示错误；不要手工修改示例元数据和 UUID 文件名。

点击名称查看只读频谱；行内播放按钮会打开频谱并试听。预览支持 1–6 通道选择、时间缩放、Alt 或中键拖动平移、重置视图、原音播放、暂停、停止和进度定位，使用当前本机监听增益、音量与输出设备。预览与主音频共用一个输出，切换时停止此前声音。关闭预览或切换身份/项目会释放预览；原项目的音频选择、标签、备注、屏蔽及分析/显示设置保持原样。预览不能创建标注或私人处理。

输出设备从“音频 → 输出设备…”或底部播放栏“更多播放操作 → 输出设备…”打开，包含系统默认和刷新设备。Escape 或点弹窗外关闭并返回入口焦点。右侧原“设备”分区由“示例”替代。

共享示例请分享整个共享项目文件夹（含 `collaboration.json`、音频和 `examples`）。现有 `.audioproj.zip` 项目包及 `.annotations.json` 标注交换文件不携带新增示例库；私人示例不会自动导出，也不会随 UUID 身份跨项目或跨电脑出现。将身份文件复制到另一电脑不会复制私人示例。

0.7.5 使用可选、单独版本的示例旁挂文件，不迁移已有项目、协作、作者层、私人设置或交换格式。未使用示例的项目无需创建示例目录；旧版客户端忽略新示例库。更新前保存并关闭程序，完整覆盖程序和配套资源，项目文件夹保持原位。
