# 0.7.8 re3（2026-10-29）

- 修复共享状态刷新引起的播放指针停顿：共享状态在独立 Worker 校验，未变化的大块数据复用；目录、回收站和维护状态不再反复触发工作区重绘。
- 将音频补充、播放进度发布和源文件检查分开。保留首次源校验及周期检查，较慢的源文件查询不再占用音频补充线程。
- 频谱按短任务绘制，所有通道共用帧预算；保持原有采样、频率映射、像素尺寸及颜色计算。绘制完成前显示真实忙碌状态。
- 音频列表仅更新改变的行，复用相同的切换菜单和刻度；白色播放线使用独立动画与合成变换，不增加音频时钟预测时长。

在 1797 条目录记录的独立副本中，模拟每次源检查延迟 1 秒，四种原音/处理后、单声道/六通道播放的实际指针更新间隔最大约 28–46 ms，未出现 100 ms 以上的停住段。旧版同一目录负载测得一次约 587 ms 停顿。另在 877 条完整合成音频、含真实屏蔽和 −6 dB 增益的项目中，间隔最大约 21–31 ms。测试均未记录到缓冲欠载；没有进行声卡回环录音，不能据此保证所有设备与网络环境绝对无卡顿。

项目、作者层、目录、回收站和交换格式保持兼容；没有迁移用户数据或改动原音频。切换音频短暂黑屏仍按此前约定暂缓。内部数字版本仍为 0.7.8，修订名为 re3；0.7.8 原版、re1、re2 均可使用对应的 0.7.8 直接更新包。

完整验证与限制：[验证记录](evidence/2026-10-29-playback-smoothness/verification.md)。更新前保存并同步，关闭程序后安装或完整覆盖程序目录，保留项目和个人数据位置。
