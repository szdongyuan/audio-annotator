# 使用说明 · 0.4.0

## 默认作者与 NAS 共享

“文件 → 新建项目”选择空目录即可开始，无需注册。单人、本机目录和 NAS 都使用同一项目；入口为 `collaboration.json`。把整个项目目录放在共享位置，同事打开即可使用自己的本机作者。该身份由当前设备的 Windows 用户稳定保存，重复打开保持同一作者；在其他电脑继续同一身份请使用可选项目账号。

“协作”菜单可注册、登录项目账号，或返回本机作者。账号密码不会记住；账号切换不会自动复制另一身份的内容。同一作者只能有一个可写会话，第二个窗口会明确拒绝写入；选择“文件 → 只读打开项目…”可查看，仍可播放、设置音量和私人屏蔽。身份缓存损坏时会报错，不会悄悄生成替代作者。

每个人只发布自己的区域、类别及文件/通道/区域备注。同一位置不同作者的框分别保留。作者显示可选全部、仅我的或勾选作者；他人框和“作者”列表提供只读详情、播放、定位，不能编辑或删除。音量、设备、屏蔽、分析、混音、视图和隐藏列表按本机身份保存，不随公开标注同步。

所有可写作者均可导入音频和文件夹。导入把验证后的音频复制到项目；公共媒体只追加，不能物理删除。他人新增音频时显示提示，选择“协作 → 更新音频列表”保存当前草稿并载入；后台轮询不会替换正在编辑的文档。媒体列表的“从我的列表隐藏”只改变本人显示，可从“显示隐藏音频”恢复；导出仍包含全部媒体。

保存先写本机，再同步共享目录。“本机未保存”表示个人更改未保存，“已存本机 · 待同步”表示共享提交待完成；错误可在状态中查看。共享目录暂时不可用时已打开的工作区仍可本机保存，恢复后重试同步；未缓存音频与首次打开不保证离线可用。共享基线冲突时保留本机内容，建议先另存，再明确确认“加载共享版本”丢弃待同步标注和本人撤销历史。

“另存我的项目副本…”复制音频与当前作者内容到新空目录，保留私人操作并切换到新的默认项目；复制过程可取消。它不是全员备份。“导出我的标注 / 项目包…”只包含本人公开标注、类别和备注，不含其他作者、密码、屏蔽及个人设置；全员协作使用原项目目录。

新项目共享清单为格式 2；旧普通格式 2 和旧协作格式 1 可显式打开，不自动迁移。旧普通项目可用“创建协作副本”复制为新项目。旧协作格式 1 仍有访客及显式复制访客标注流程，媒体目录固定。项目账号提供可信共享目录内的应用级隔离，实际文件访问由目录 ACL 管理。

## 新建与导入

从“文件 → 新建项目”选择空文件夹，再导入 WAV、FLAC 或 MP3（1–6 通道）。原始音频不被修改；导入会校验指纹、复制原音频并建立解码缓存。文件列表可搜索；音频缺失或改变时提供重新关联入口，只接受指纹及元数据匹配的原件，并保留类别和备注。

“文件 → 导入文件夹”默认只扫描所选目录，可勾选“包含子文件夹”。扩展名大小写不敏感，不跟随目录内的符号链接、junction 或其他 reparse point。已经作为项目源引用的相同规范路径跳过。新版项目引用复制后的文件，重新选择外部原始文件会产生独立条目；相同内容不会合并。最多检查 100000 个条目并接受 10000 个候选音频；扫描超限时要求缩小目录，不导入半份结果。扫描后按相对路径排序，以最多 256 个路径一批串行导入。

进度可取消，已成功加入的媒体保留，后续扫描和解码停止。结果分别显示成功、失败、已存在和跳过的数量，并分页查看明细。损坏文件不会冒充成功。遇到未提交的失败更改时，先使用提示中的重试或放弃处理，再继续批次；切换或关闭项目会取消旧任务。

## 频谱与对比

“视图”选择单文件或双文件。双文件默认左右排列，可切换上下排列；分隔线比例限制为 25%–75%，随项目保存。多通道可选择显示的通道，超过可用空间时在各文件内滚动；每张频谱保持最低绘制高度。小窗口可收起两侧面板。“联动时间轴”按真实秒数同步两个文件，短文件尾部留空。

普通滚轮缩放时间，Shift+滚轮缩放频率；中键拖动或 Alt+左键拖动平移。沿时间或频率刻度拖出范围可局部放大，刻度右键可放大、缩小或重置该轴。Ctrl+滚轮调整 STFT 线性/对数混合：向上更对数，向下更线性；梅尔模式保持固定映射。这些操作不改变标注的秒/Hz。

分析和显示设置从“视图”或文件标题打开，可调整窗函数、窗长、FFT、hop、梅尔带数、色阶、增益和动态范围。计算期间可取消，取消或失败后可重试。过期计算不会覆盖新视图。设置浮窗点击外部或 Escape 关闭；外部关闭点击不穿透画框，可直接切换另一文件设置。两侧文件独立选择；重复选择已在另一侧显示的文件会短暂高亮另一侧，不自动交换。

## 选区、分类与备注

无需切换工具，直接左键拖出临时矩形。临时选区不会写入项目，也不创建撤销项。右键选区可选择类别、填写备注、播放、屏蔽或放大到选区。分类/备注会创建标注，之后再选类别更新同一个标注。单击已有框选择对象，拖边缘移动，拖控制点改变范围；激活框内部可抓取移动；框外第一次操作仅取消激活，再次拖动才创建新框。取消激活保留标注与屏蔽效果。有效激活框附近提供“播放”和“标注”悬浮工具条，手势期间隐藏。所有框内部透明。

文件标题和通道标题提供独立类别入口，也可通过右键或“标注”菜单操作。文件、通道、区域的类别与备注互不继承、互不覆盖；整段分类无需拖全图矩形。类别管理可新增、改名、改色和删除。删除类别前显示三层引用数量，确认后清空引用但保留对象及备注，一次撤销恢复全部引用。类别筛选区分文件、通道和区域，选择结果可定位对应对象。

Delete 表示屏蔽当前范围，不删除标注；相同范围已有屏蔽时复用并启用。删除对象请使用“删除标注”或“删除屏蔽”明确菜单项。标注和同范围屏蔽是独立对象，不自动同步。Escape 取消当前拖动或清除选区，菜单打开时先关闭菜单。文本输入、菜单和对话框内的快捷键不会误操作音频。

## 试听与屏蔽

底部提供播放/暂停、停止、定位、循环、音量和声音版本。默认“暂存编辑”同时控制两侧频谱与普通播放；“原音”忽略屏蔽。空格和普通播放自动使用激活选区，没有激活选区时播放当前文件。“音频”菜单打开输出设备、播放源和通道混音。右键或悬浮条可明确“试听选区原音”或“试听选区（应用屏蔽）”，仅覆盖本次试听且保留工作区声音版本；仅输出选中通道及物理时间/频率范围，无需先保存标注。暂停保留位置，停止返回本次起点；循环按文件或选区范围进行。

右键记录固定白色虚线定位点，不改变当前选区或立即播放。“从此处播放”从该文件定位秒数播放至文件末尾；“播放整段”显式覆盖当前选区。暂停/继续保留覆盖，停止或结束后下一次普通播放恢复自动范围。

屏蔽可以开关、移动、调整、删除与撤销，暂存编辑频谱随实际处理结果更新。切换“原音”可临时忽略全部屏蔽，切回“暂存编辑”恢复应用。混音先选择独听集合，再应用静音；3–6 通道平均混为居中声道。设备断开后可刷新并重试。输出计数用于诊断，不代表人工听感检查。

频段处理使用固定 2048 点 FFT、512 hop、Hann 窗、重叠相加及时间/频率淡变，独立于显示参数。48 kHz 下频率 bin 约 23.44 Hz；窄频带、瞬态和边界存在泄漏与时间扩散，不能精确分离叠加声源。重叠屏蔽取并集，不重复衰减。

## 保存、恢复和格式

新默认项目保存不可变公共媒体、分作者标注和账号验证值；私人文档及恢复数据存放在本机。恢复提示必须明确选择有效版本，异常不会自动丢弃待同步工作。旧普通项目使用 `project.json`、`recovery.json` 和有效备份，缓存可重建。旧/未来版本、未知字段和不安全路径会明确拒绝，不自动修改源文件。

保存失败保留内存和草稿，可重试或另存。普通打开先保存关闭当前会话，再尝试目标；打开失败后可重新打开原项目。身份切换、目录更新、分享导入通过保存屏障，失败时保持原会话可用。

## 分享与接续工作

- 默认“我的项目包（含音频）”`.audioproj.zip`：包含全部验证后的音频和本人三层标签、类别及区域；不含其他作者、屏蔽、私人设置、缓存、恢复或账号凭据。接收方可一步导入。
- “我的标注（不含音频）”`.annotations.json`：不带音频及本机路径。导入时先为每个条目选择相同原始音频；全部指纹和元数据校验通过后才建立项目。选错可更换重试，取消保留当前项目。

导入在所选父目录创建独立默认项目和新项目 ID，以当前本机作者拥有导入标注，不合并或覆盖当前项目。完整 ZIP 无需关联。错误、取消只清理本次拥有的暂存内容。导出目标已存在时拒绝覆盖，请选择新名称。
