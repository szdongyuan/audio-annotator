# 使用说明 · 0.7.3

## 全局身份与 NAS 共享

首次启动会在本机保存一个 UUID 身份，记住上次选择。无需项目即可从“协作”菜单创建身份、切换身份、修改昵称、导入或导出身份。同一昵称可以对应不同 UUID；列表展示短 UUID，可展开完整 UUID。没有注册、密码或登录。

“文件 → 新建项目”选择空目录即可开始。单人、本机目录和 NAS 使用相同项目入口 `collaboration.json`。当前身份的 UUID 在所有项目中保持不变；同事使用自己的身份打开共享目录即可协作。同一 UUID 在同一项目只能有一个可写会话，第二个窗口明确拒绝写入；可选择“文件 → 只读打开项目…”查看、播放及设置私人音量和屏蔽，不会自动换身份。

在另一电脑继续同一作者：先“导出当前身份…”，再在另一电脑“导入身份…”，最后明确点击“使用此身份”。导入不会自动切换；相同 UUID 已存在时保留本机昵称和创建时间。身份文件仅包含 UUID、昵称、创建时间，不带音频、标注、路径、私人屏蔽或设置。项目音频和公开标注通过共享项目目录或项目包传递；同一 UUID 在另一电脑会使用该电脑独立的私人工作区。

修改昵称不改变 UUID 或创建时间。当前可写项目立即更新作者显示名称，其他项目下次以该身份打开时更新；不会扫描或改写其他项目。远程作者列表通过正常同步看到项目昵称，各电脑已保存的本机昵称不被覆盖。本机改名成功但项目更新失败时显示具体提示并保留工作。切换身份先保存草稿；失败时保留原身份和工作区，创建成功但使用失败的新身份仍可在列表选择。选择当前身份不改变历史或选区。损坏的本机身份文件会报错，不会自动替换 UUID。

每个人只发布自己的区域、类别及文件/通道/区域备注。同一位置不同作者的框分别保留。作者显示可选全部、仅我的或勾选作者；他人框和“作者”列表提供只读详情、播放、定位，不能编辑或删除。音量、设备、屏蔽、分析、混音、视图和隐藏列表按本机身份保存，不随公开标注同步。

所有可写作者均可导入音频和文件夹。导入把验证后的音频复制到项目；公共媒体只追加，不能物理删除。他人新增音频时显示提示，选择“协作 → 更新音频列表”保存当前草稿并载入；后台轮询不会替换正在编辑的文档。媒体列表的“从我的列表隐藏”只改变本人显示，可从“显示隐藏音频”恢复；导出仍包含全部媒体。

保存先写本机，再同步共享目录。“本机未保存”表示个人更改未保存，“已存本机 · 待同步”表示共享提交待完成；错误可在状态中查看。共享目录暂时不可用时已打开的工作区仍可本机保存，恢复后重试同步；未缓存音频与首次打开不保证离线可用。共享基线冲突时保留本机内容，建议先另存，再明确确认“加载共享版本”丢弃待同步标注和本人撤销历史。

“另存我的项目副本…”复制音频与当前作者内容到新空目录，保留私人操作并切换到新的默认项目；复制过程可取消。它不是全员备份。“导出我的标注 / 项目包…”只包含本人公开标注、类别和备注，不含其他作者、密码、屏蔽及个人设置；全员协作使用原项目目录。

最终格式为 ProjectDocument 3、协作清单 5、作者层 2、私人工作区 2、交换文件 4、DSP 2；组织目录 1、媒体目录 2、分析算法 1。旧格式明确拒绝，不迁移或改写。请使用对应旧版程序处理旧项目。身份用于可信团队的作者归属，无需服务器或登录。

## 新建与导入

从“文件 → 新建项目”选择空文件夹，再导入 WAV、FLAC 或 MP3（1–6 通道）。原始音频不被修改；导入会校验指纹、复制原音频并建立解码缓存。文件列表可搜索；音频缺失或改变时提供重新关联入口，只接受指纹及元数据匹配的原件，并保留类别和备注。

“文件 → 导入文件夹”或“导入 ZIP 音频”使用相同流程：选择来源、导入方案，点击“扫描预览”，确认后点击“导入 N 个音频”。默认递归扫描，支持 WAV/FLAC/MP3；ZIP 可多选，普通音频 ZIP 与“导入标注文件或完整项目包”是两个入口。预览不会修改项目，取消预览不会导入；改变规则后必须重新扫描。列表显示记录名与文件名，悬停、搜索和无障碍名称保留完整来源路径。

“通用·保留来源目录”保留来源名和目录；“通用·平铺”将候选放到目标目录。“精成·按结果和故障分类”使用来源/结果/故障/记录分组；“精成·保留来源目录”保留目录并去掉 audio 组件。两种精成方案支持 jingcheng-run-export-record/v2 清单，包括原始 records 路径和清洗后移位目录。“导入第二路音频”默认勾选；取消后仅选择清单 position 1。这是逻辑录音路数：第一路可能是 CH2，第二路可能是 CH4，不能按文件编号或 WAV 自身声道数判断。缺少、损坏或歧义清单列为问题，不猜测；可改用通用规则。分类目录不会自动生成标签。

在“路径规则”中用换行、逗号或分号分隔多条规则；任一包含规则匹配、且不匹配任何排除规则才入选。路径用 /，匹配不区分大小写。* 匹配单层字符、? 匹配一个字符、** 跨目录；**/ 可匹配零层。便捷写法 */CH1 或 */CH2 匹配任意深度对应音频，可省略扩展名，但 */CH1 不匹配 CH10.wav。规则可保存为最多 32 个本机预设，内置规则不能覆盖；只记住规则，不保存来源绝对路径，不随项目共享。本机存储容量超限会显示错误并保留已存规则，本次设置仍可使用。

不跟随符号链接、junction 或 reparse point。仅跳过已作为项目源引用的相同规范路径；重新选择外部原件会产生独立条目，相同内容和不同 ZIP 的同名文件不会合并。ZIP 只提取入选音频，拒绝不安全路径、重复条目、加密或不支持的格式；不支持 RAR/7z/嵌套 ZIP。最多 32 个 ZIP、100000 个条目、10000 个候选、原生批次最多256项、界面每页50项；单音频上限 1 GiB、总入选原始字节 20 GiB、单清单 1 MiB、规则共 256 条且每条 512 字符。问题详情最多保留 256 项，数量单独统计。超限要求缩小范围，不静默截断。

导入分批（每批最多 256）提取、校验、复制和解码原始音频。项目持有独立原始字节，移动或删除来源 ZIP 后仍可使用；暂存路径不作为最终来源。扫描后来源改变要求重新扫描。导入中取消保留已接收音频；失败会显示详情，可“重试并继续导入”或“结束并放弃失败项”，释放失败保留重试入口。可配置来源导入要求可写当前协作项目；当前普通项目仍可直接导入音频。


进度可取消，已成功加入的媒体保留，后续扫描和解码停止。结果显示成功、失败、跳过及扫描问题的数量，并分页查看明细。损坏文件不会冒充成功。遇到未提交的失败更改时，先使用提示中的重试或放弃处理，再继续批次；切换或关闭项目会取消旧任务。

## 频谱与对比

“视图”选择单文件或双文件。双文件默认左右排列，可切换上下排列；分隔线比例限制为 25%–75%，随项目保存。多通道可选择显示的通道，超过可用空间时在各文件内滚动；每张频谱保持最低绘制高度。小窗口可收起两侧面板。“联动时间轴”按真实秒数同步两个文件，短文件尾部留空。

普通滚轮缩放时间，Shift+滚轮缩放频率；中键拖动或 Alt+左键拖动平移。沿时间或频率刻度拖出范围可局部放大，刻度右键可放大、缩小或重置该轴。Ctrl+滚轮调整 STFT 线性/对数混合：向上更对数，向下更线性；梅尔模式保持固定映射。这些操作不改变标注的秒/Hz。

分析和显示设置从“视图”或文件标题打开，可调整窗函数、窗长、FFT、hop、梅尔带数、色阶、增益和动态范围。计算期间可取消，取消或失败后可重试。过期计算不会覆盖新视图。设置浮窗点击外部或 Escape 关闭；外部关闭点击不穿透画框，可直接切换另一文件设置。两侧文件独立选择；重复选择已在另一侧显示的文件会短暂高亮另一侧，不自动交换。

## 选区、分类与备注

无需切换工具，直接左键拖出临时矩形。临时选区不会写入项目，也不创建撤销项。右键选区可选择类别、填写备注、播放、屏蔽或放大到选区。分类/备注会创建标注，之后再选类别更新同一个标注。单击已有框选择对象，拖边缘移动，拖控制点改变范围；激活框内部可抓取移动；框外第一次操作清除临时框或取消已保存框的激活，再次拖动创建新框。一次空白单击同时设置该音频白色虚线及下次起点；已保存标注仍保留。有效激活框附近提供“播放”和“标注”悬浮工具条，手势期间隐藏。所有框内部透明。

文件标题和通道标题提供独立类别入口，也可通过右键或“标注”菜单操作。文件、通道、区域的类别与备注互不继承、互不覆盖；整段分类无需拖全图矩形。类别管理可新增、改名、改色和删除。删除类别前显示三层引用数量，确认后只移除该标签引用，保留其他标签、对象及备注，一次撤销恢复全部引用。类别筛选区分文件、通道和区域，选择结果可定位对应对象。

Delete 对已选标注框删除标注本身；对临时选区屏蔽当前范围，成功后清除选区，不留下可抓取处理框。处理列表可启停、定位视图或删除记录；标注与处理独立。Escape 取消当前拖动或清除选区，菜单打开时先关闭菜单。文本输入、菜单和对话框内的快捷键不会误操作音频。

## 试听与屏蔽

中央频谱下方的一条播放栏提供播放/暂停、停止、定位、循环、音量、声音版本、监听增益和更多操作。窄窗口的区域增益、重置视图和重置屏蔽在同栏“•••”中。作用于最近交互的音频；比较选择器和分析设置不会切换播放源。默认“暂存编辑”同时控制两侧频谱与普通播放；“原音”忽略全部私人屏蔽和区域增益。空格和普通播放自动使用激活选区，没有激活选区时从当前文件的白色虚线起点播放。“音频”菜单打开输出设备、播放源和通道混音。右键或悬浮条可明确“试听选区原音”或“试听选区（应用屏蔽）”，仅覆盖本次试听且保留工作区声音版本；仅输出选中通道及物理时间/频率范围，无需先保存标注。暂停保留位置，停止返回本次起点；循环按文件或选区范围进行。

右键记录固定白色虚线定位点，不改变当前选区或立即播放。“从此处播放”从该文件定位秒数播放至文件末尾；“播放整段”显式覆盖当前选区。暂停/继续保留覆盖，停止或结束后下一次普通播放恢复自动范围。

屏蔽可在处理列表开关、删除与撤销；定位仅改变视图，不产生可拖动框。暂存编辑频谱随实际处理结果更新。切换“原音”可临时忽略全部屏蔽，切回“暂存编辑”恢复应用。混音先选择独听集合，再应用静音；3–6 通道平均混为居中声道。设备断开后可刷新并重试。输出计数用于诊断，不代表人工听感检查。

频段处理使用固定 2048 点 FFT、512 hop、Hann 窗、重叠相加及时间/频率淡变，独立于显示参数。48 kHz 下频率 bin 约 23.44 Hz；窄频带、瞬态和边界存在泄漏与时间扩散，不能精确分离叠加声源。重叠屏蔽取并集，不重复衰减。

## 保存、恢复和格式

新默认项目保存不可变公共媒体、分作者标注和 UUID 作者元数据；私人文档及恢复数据存放在本机。恢复提示必须明确选择有效版本，异常不会自动丢弃待同步工作。普通项目使用 `project.json`、`recovery.json` 和有效备份，缓存可重建。旧/未来版本、未知字段和不安全路径会明确拒绝，不自动修改源文件。

保存失败保留内存和草稿，可重试或另存。普通打开先保存关闭当前会话，再尝试目标；打开失败后可重新打开原项目。身份切换、分享导入通过保存屏障；共享目录刷新独立进行，保留个人草稿和撤销历史。身份与交换操作失败时保持原会话可用。

## 分享与接续工作

- 默认“我的项目包（含音频）”`.audioproj.zip`：包含全部验证后的音频和本人三层标签、类别及区域；不含其他作者、屏蔽、私人设置、缓存、恢复或身份文件。接收方可一步导入。
- “我的标注（不含音频）”`.annotations.json`：不带音频及本机路径。导入时先为每个条目选择相同原始音频；全部指纹和元数据校验通过后才建立项目。选错可更换重试，取消保留当前项目。

导入在所选父目录创建独立默认项目和新项目 ID，以当前所选 UUID 身份拥有导入标注，不合并或覆盖当前项目。完整 ZIP 无需关联。错误、取消只清理本次拥有的暂存内容。导出目标已存在时拒绝覆盖，请选择新名称。

## 共享目录与导入布局

左侧音频为紧凑单行列表，完整来源、标签和采样率在悬停属性中；右键可隐藏、移动或重新关联。目录支持创建、重命名、移动和删除空目录；隐藏音频仍使目录非空。目录和音频归属由全部作者共享，标签、备注、隐藏和私人处理独立。搜索音频或目录会展开匹配祖先。并发修改冲突保留输入，核对刷新后的目录再明确重试。

导入先选择目标文件夹和完整导入方案；高级解析、递归、路径规则、外包来源、去除组件及模板默认折叠。预览显示完整结果目录，每页最多50个媒体；修改来源、目标或布局必须重扫。精成可选第二逻辑路；缺少可选字段使用“日期未知 / 未分类 / 型号未知 / 记录未知”分组并显示问题，不推测。最多32个本机自定义方案包含发现和布局规则，不保存来源路径或目标目录UUID。

## 多标签与增益

文件、通道和区域可各自连续勾选多个标签（每目标最多64个），菜单保持打开，重复勾选可取消，“清空标签”一次清空。Escape或点外关闭；Space/Enter切换。一个临时框首次分类只创建一个标注，后续标签更新该标注；备注保持不变。他人的全部标签只读。框颜色取类别定义顺序中首个已选标签。

监听增益是私人工作区偏好：全局默认0dB，此音频可设绝对覆盖，范围−60至+24dB，步长0.1dB。单音频值不与全局相加；“恢复跟随全局”清除覆盖。播放中调整不重启或跳动位置，也不修改频谱/历史。输出音量仍为独立0–1标量。原音与处理后播放均应用监听增益。

区域增益对选区显式输入并“应用增益”，范围−60至+24dB；0dB不产生编辑。它属于可撤销私人DSP，同一区域重复增益会累加，完全屏蔽处仍为零。成功后清除选区，已有标注和标签保留；失败保留输入以便重试。重置屏蔽一次移除当前音频所有通道的屏蔽（包括禁用记录），保留区域增益、其他音频、标注和监听；一次撤销全部恢复。重置视图恢复全时间/频率范围，保留分析、显示参数、通道和处理。

播放中同一音频空白单击仅更新下次起点；暂停后再播放采用新起点。实际点击另一音频频谱遵循切换播放源的停止/重置行为。原音绕过私人DSP，原始文件始终不改写。

项目包默认勾选“保留目录结构”，音频使用安全的原文件名；取消后平铺到audio/，逻辑目录仍完整往返。中文、同名和文件/目录冲突由原生预览稳定消歧，空目录保留。预览过期需刷新后再导出。只导出本人公开标签/备注和音频；监听、音量、屏蔽、区域增益和他人内容不共享。“另存我的项目副本…”保留本人私人状态和包括隐藏媒体在内的目录。

## 0.7.1 快捷操作与更新

上下方向键按当前目录与搜索结果切换上一段或下一段音频；自动展开目标目录，跳过隐藏音频和对比面板正在显示的音频，到首尾不循环。输入备注、数值、搜索或操作菜单时保留原有按键行为。点击左侧音频同时将其设为播放源，不会自动播放；两侧面板下拉选择仍相互独立。

按 R 在当前目录（含子目录）、搜索和筛选结果中随机打开本人未分类音频；折叠目录不缩小范围，打开后自动展开并聚焦目标条目。打开时停止原播放，不自动播放新音频，按空格即可试听；对比面板保持不变。输入控件与菜单/对话框内不触发 R。

本功能按三层标签判断：本人文件、任一通道或任一局部区域有标签，整条音频都不参与；只有无标签区域框仍可参与，备注、私人屏蔽、区域增益及他人标签不影响。已有“未标注”筛选仍按原义排除含区域标注的音频，R 不会把被当前筛选排除的音频重新加入。分类、移除最后一个标签、撤销或重做后，下次按 R 立即使用最新状态。

有其他候选时避免连续打开同一条，每次独立抽取，之前打开过的未分类音频仍可再次出现。无候选时提示“当前范围内没有未分类音频”，只有当前音频符合时提示“没有其他未分类音频”；这两种情况保持当前选择、播放源和播放状态。

拖动音频列表右边界调整宽度，双击边界恢复默认；宽度仅保存在本机。文件行右键“复制文件名”复制带扩展名的原始文件名称。复制失败时提示可手动复制的名称。

播放栏直接输入监听 dB，立即设置当前音频的绝对监听增益；旁边的 dB 按钮可设置全局或恢复跟随。选区建立后，在同栏“区域”输入 dB 并按回车或 ✓ 应用，可撤销；输入过程不创建处理。首次播放无需先右键，即显示起播虚线及播放指针。

大批量导入仍按每批最多256个处理；类别保存期间防止重复提交，并在排队后按最新状态核对名称。真正的失败修改仍须明确重试或放弃，已导入音频保留，不会因数量较多而自动丢弃。

0.7.1 保持0.7.0所有项目、协作、标注、私人工作区和身份格式不变。更新前保存并同步、关闭程序；将更新包中的程序与配套资源覆盖到原程序目录即可。保留项目/NAS目录及本机用户数据；无需重新导入音频或创建身份。更早的不同格式项目仍按原有版本规则处理。


## 0.7.2：全局设置与共享类别

右上角“全局设置”控制本机的播放、显示与分析偏好。设置监听增益（例如 +20 dB）、STFT 或梅尔、STFT 的线性/对数比例（0% 为完全线性），点击“应用到全部音频”。这些设置跨音频、项目及重启保留，也用于后来导入的音频，不会同步到其他人的电脑或包含在项目分享包中。梅尔频谱使用固定梅尔坐标，STFT 的线性/对数比例保留到切换回 STFT 时使用。

音频面板内“设置”仍只修改当前音频；点击“恢复跟随全局显示与分析”可取消该音频的例外。播放栏的小增益输入框只改变当前音频的监听增益，可在 dB 菜单的“此音频”中恢复跟随全局。再次“应用到全部音频”会清除已有例外并统一设置。显示增益改变频谱亮度，监听增益改变输出响度，均不改写原音频。

选中已有标注框时，Delete 删除标注本身；框出的临时选区按 Delete 则屏蔽对应时频范围。两者均可撤销、重做。输入框和菜单内的 Delete 保留原有编辑行为。

同事保存并同步后，其类别会出现在分类菜单与“类别 → 共享类别”中。可以直接为自己的区域、文件、通道选用这些类型，也可以点击“采用”加入自己的类别。自己的同名类别会被复用，各作者的类别和标注仍独立保存。修改或删除自己的类别不会修改同事的数据。作者过滤只隐藏标注框，不隐藏可使用的共享类别。


## 批量整理音频（0.7.3）

点击音频列表标题旁的多选图标，勾选音频或文件夹后使用列表底部的操作条。文件名仍用于查看频谱；Ctrl 点击切换选择，Shift 点击选择连续范围，Ctrl+A 选择当前目录与筛选范围的全部音频（含折叠子目录），Esc 退出多选。

放大镜输入框搜索文件名和目录路径。筛选图标展开“我的标注 / 我的标签”和“搜索整个项目”。修改搜索、筛选或当前目录会清空批量选择，避免误操作不在结果中的文件。

列表视图可切换正常音频、我的隐藏和共享回收站。隐藏仅影响自己，可撤销或批量取消隐藏。移入回收站需要确认，将在所有新版协作者的正常列表移除音频，但保留音频本体、各作者标注与目录位置，支持批量恢复，不支持永久删除。恢复时仍保持各人的隐藏设置。文件列表拥有焦点时 Delete 打开回收站确认；频谱上的 Delete 仍删除选中的标注框或屏蔽临时选区。

导出标注/项目包不包含回收站里的音频。另存自己的项目副本保留回收站和自己的标注/私人操作。共享项目直接打开原 collaboration.json 即可；所有协作者应更新到 0.7.3，旧客户端忽略 recycle.json，会继续显示已回收音频。
