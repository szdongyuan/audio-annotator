# 使用说明

## 新建、导入与观察

从“项目 → 新建项目”选择一个空文件夹。使用“导入音频”选择 WAV、FLAC 或 MP3；每个文件支持 1–6 个通道。导入会校验指纹并建立临时解码缓存，不修改原音频。文件列表可搜索；缺失或内容改变会显示状态及重新关联入口。导入失败不会留下假成功媒体，可以处理原因后重新选择文件。

选择文件后，用上方通道按钮选择可见通道，“全部”展开全部通道。取消所有通道后显示选择提示。双文件对比上下排列；各通道区域可滚动。小屏幕可收起两侧面板。勾选“联动时间轴”后，两文件按真实秒数同步浏览，不把短文件拉伸到长文件。

滚轮缩放时间，Shift+滚轮缩放频率；拖动空白处平移。频谱类型切换 STFT/梅尔；STFT 的线性—对数滑块只改变显示坐标，不改变标注 Hz。分析设置中可调整窗函数、窗长、FFT、hop、梅尔带数、色阶、增益和动态范围。计算期间可取消，取消或失败后可重试。过期任务不会覆盖新视图。

## 区域、备注和屏蔽

切换“标注”工具，在通道频谱中拖出矩形。区域属性提供精确秒/Hz、类别和备注；选择工具可以移动或拖动边角调整范围。“类别”分区可新增、改名、改颜色或删除；删除类别会明确提示受影响区域数量，并保留区域与备注。

音频备注、通道备注、区域备注互相独立。切换对象、保存或关闭前会提交文本草稿。列表可筛选并定位区域。输入框内的 Delete、撤销快捷键不删除项目区域。

“屏蔽”工具建立暂存编辑，源文件仍保持原样。屏蔽可以开关、定位、移动、调整、删除与撤销。原音模式忽略屏蔽；处理后模式应用屏蔽；选区模式还可选择原始选区或处理后选区。选区试听只输出选定通道和时间/频率范围。

频段处理使用固定 2048 点 FFT、512 hop、Hann 窗、重叠相加和时间/频率淡变，独立于显示参数。48 kHz 下频率 bin 约 23.44 Hz；特别窄的频带、瞬态和边界存在窗函数泄漏与时间扩散。它不是精确分离叠加声源的工具。重叠屏蔽取并集，不重复衰减同一区域。

## 播放

选择播放源和本机输出设备后播放。暂停保留位置，停止返回本次播放起点；循环按选区或文件范围进行。“混合”分区保存每个媒体的独听/静音选择：先选择独听集合，再应用静音；3–6 通道平均混为居中声道。播放设备断开后可刷新设备并重试。输出计数用于诊断，不代表已进行人工听感检查。

| 快捷键 | 操作 |
|---|---|
| Ctrl+S | 保存项目 |
| Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | 撤销 / 重做 |
| V / A / M | 选择 / 标注 / 屏蔽 |
| Delete | 删除所选区域或屏蔽（文本输入时除外） |
| Escape | 取消当前拖动/选区预览 |
| 空格 | 播放 / 暂停（文本输入时除外） |
| ← / → | 聚焦频谱时浏览时间 |

## 保存、恢复和关联

项目文件夹内 `project.json` 是正式文档，`recovery.json` 和有效备份用于恢复；缓存可重新生成。保存显示“已保存”后再移动文件夹。保存失败时保留内存内容和草稿，可重试或另存到新的空文件夹。关闭遇到未处理错误时会询问，放弃更改会丢弃内存内容。不要在应用运行时手工编辑项目文件。

异常退出或正式文档损坏时，应用提供经过校验的恢复版本；可以恢复、保留正式版本（若有效）或取消打开。同一项目具有写锁，避免两实例同时写入。

原音频被移动时，用“重新关联”选择同一份文件；应用核对字节指纹及音频元数据。相似文件名不够，内容不同会拒绝关联。保留音频原件和项目备份；本地路径可能包含 Windows 扩展路径前缀，这是内部规范路径表示。

## 文件交接

“项目 → 分享项目”先保存当前一致版本，再导出：

- 仅标注 `.annotations.json`：包括区域、类别、备注、分析、屏蔽、混合和视图，不包含原音频绝对路径。接收方导入后逐个关联原件。
- 完整 `.audioproj.zip`：还包含经校验的原音频字节。不会包含缓存、恢复或备份文件。

“导入分享文件”会在所选父文件夹中新建独立项目，使用新的项目 ID，不直接合并或覆盖当前项目。未知格式版本、不安全解压路径、悬空引用、非法范围、损坏媒体或指纹不符会明确失败。目标文件已存在时当前版本拒绝覆盖，请选择新文件名。取消或失败只清理本次导入的暂存目录。
