# 0.7.8 测试版

- 多层目录采用一致的文件缩进；个人目录树/平铺模式保留显示范围和展开状态，上下键可跨目录揭示目标。
- 同事提交的新增音频在空闲时自动载入，播放与交互期间暂缓；共享回收站继续保留全部作者内容和原音频。
- 下次启动提示恢复上次项目、面板、属性页及定位线，始终停止播放；不可用路径可以重试或更换项目。
- 作者页包括自己。作者及本人列表条目打开统一只读频谱查看窗口，支持独立分析、通道、缩放及原音/处理后试听；显式跳转才定位主工作区。他人区域仅可通过可见边框点选。
- 按作者或显示类别名称隐藏框及列表条目，批量操作可选择包括自己；偏好仅保存在本机项目/身份中。
- 包含上游 R 随机打开未分类音频快捷键；候选遵循当前显示目录、搜索和筛选，不自动播放。
- 播放指针采用单调呈现时钟。已记录的 Windows 测量中 RAF p95 约 16.7 ms，测试设备未观察到 underrun；未做音频回环采集，不声称修复主观听感。

项目、作者层、媒体目录、目录组织、回收站及交换格式保持兼容，无需迁移。示例库和现有私人处理、历史及导出语义保留。重复导入仍按原行为：重新选择外部原件会创建独立条目，同内容不自动去重；导入/去重改造暂停。类别治理仅讨论，其他作者评价/复标延期。

实际验证范围与限制见 [验证记录](verification-0.7.8.md)。安装包及完整更新包单独生成；不会自动安装、合并或发布 GitHub Release。
