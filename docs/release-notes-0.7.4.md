# 0.7.4 测试版

- 修复回收站删除、恢复以及目录编辑与后台同步争用导致的“Collaboration job already running”。短暂争用自动等待，真实版本冲突仍要求核对。
- 导入过程中暂停后台自动同步，结束、取消或暂停后恢复；合并密集进度更新，避免逐文件重绘整个界面。
- 导入采用有界批量提交；ZIP 在一批音频内复用已解析的目录，减少逐条扫描开销。共享目录并行读取，仍逐条验证内容、路径和已保存记录。
- 运行时保留最多 64 个已解码音频，并按 256 MiB 目标控制缓存（单个超大音频及正在使用的资源可超过目标）。淘汰后仍保留校验状态，播放或分析时自动重建。
- 对 Windows / NAS 短暂文件占用造成的元数据原子替换失败进行有限重试，支持取消；持续失败保留原文件和重试信息。
- 上下键切换音频时展开必要目录，并将焦点和滚动位置同步到左侧文件行。点击文件后可直接按空格播放，导入期间仍可浏览音频。
- 修复大量音频时待关联检查及设置校验的交叉遍历，状态检查保持单个请求进行。
- 文件夹计数不再受所选文件夹影响；导入新增音频后立即请求刷新目录。

现有音频、标注、身份、私人设置、目录和回收站文件格式不变，无需重新导入已标注的音频。这是用于 PR 评审的测试构建，尚未合并至 main 或发布正式 Release。

关闭软件后将更新包完整覆盖到程序目录即可，无需逐版升级。项目文件夹保持原位；不要把更新包解压进共享项目。

要将 ZIP 中的音频平铺到 `20261026NG`：先在音频列表新建该文件夹，在“导入 ZIP 音频”中选择目标文件夹 `20261026NG`，目录布局选择“平铺”，再扫描预览。精成数据可使用“精成·保留来源目录”方案后将布局改为“平铺”；第一路/第二路选择继续生效。
