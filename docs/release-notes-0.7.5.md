# 0.7.5 测试版

- 新增项目内“示例”分区：我的示例、共享示例、自定义名称、名称搜索、重命名、移除、范围复制及添加当前音频。共享条目由创建者管理。
- 示例复制原始音频，移走外部来源后仍可查看频谱和试听。只读预览支持六通道选择、缩放、平移、定位、播放、暂停和停止，保留主项目的标注和私人处理。
- 输出设备改为独立弹窗，从音频菜单及底部更多操作打开；提供系统默认、设备刷新，移除界面帧诊断计数。窄窗仍可访问全部属性分区。
- 身份操作遇到保存后后台发布的短暂任务占用时有限等待重试；已经创建的身份保留原 UUID，真实 I/O 或版本冲突仍明确提示。

示例仅属于当前项目。私人示例还绑定本机当前 UUID 身份；共享示例随整个共享项目文件夹传递。现有项目包和标注交换文件不包含新增示例库，详见 [示例使用说明](examples.md)。

现有项目、音频、标注、身份、私人设置、目录、回收站和交换文件格式均不变，无需迁移或重新导入。关闭软件后将更新包完整覆盖到程序目录；不要解压进共享项目。此版本用于本地测试交付，不发布 GitHub Release。
