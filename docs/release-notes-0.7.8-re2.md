# 0.7.8 re2（2026-10-29）

- 标注查看窗口改为紧凑工具栏，支持最大化、拖动缩放；目标框在重置、缩放和分析参数变化后保留。
- 查看窗口只试听原音和目标区域，移除私人“处理后”来源；右键可定位白色虚线并从该处播放，暂停后继续保留当前位置。
- Ctrl+0 重置当前频谱范围，适用于主工作区和查看窗口。
- 作者页合并重复显示控件，按项目与本机身份记住作者折叠状态；类别行直接提供眼睛按钮，隐藏范围改为“所有人的标注／仅其他人的标注”。
- 无有效暂存编辑时，处理后播放直接读取逐采样一致的 PCM；合并音频生产线程重复的 NAS 元数据查询，保留初始验证与 250 ms 检查。播放指针更新不再每帧提交 React 渲染。

此次先不继续优化切换音频时的短暂黑屏。未修改标注共享格式、音频原件或频谱分辨率。程序内部版本仍为 0.7.8，修订标签为 re2；0.7.8 原版或 re1 均可直接使用对应 0.7.8 更新包。

在拥有 877 条音频的独立测试项目中，单声道及六通道、原音及含屏蔽/增益的处理后播放均未记录到缓冲欠载，监听增益变化不重启音频流。逐采样一致性、处理数值、暂停、继续、定位、循环及查看窗口组合操作已验证。尚无声卡回环录音，不能据此保证所有设备和 NAS 环境都绝对无卡顿。

支持协作格式 5/6；首次确认永久删除仍会将格式 5 升级至 6，旧版无法打开升级后的项目。请先保存、同步并关闭软件，再安装或覆盖程序目录，保留项目与个人数据位置。
