# 0.7.3 验证记录

## 代码与兼容范围

从 main 的 fe5536a（0.7.2）直接更新。新增共享回收站旁文件 recycle.json（格式 1），既有项目、作者图层、目录、私人工作区和身份格式不变。个人隐藏仍写入本机私人工作区。共享媒体目录保持追加式，回收和恢复均不移除媒体描述、作者图层或原始音频。

## 自动验证

- 前端：71 个测试文件、597 项测试全部通过；构建前 TypeScript 检查通过。
- Rust：12 项核心单元测试、14 项共享私人工作区测试、1 项回收站集成测试通过，共 27 项。覆盖整批未知 ID 拒绝、隐藏原子写入、共享版本冲突、提交前拒绝、重试不覆盖已恢复状态、原音频/目录/作者图层不变、导出投影以及损坏记录保留。
- 实际 Windows Tauri 双客户端：两套独立本机身份和 WebView，真实鼠标键盘完成 6 组组合场景。目录多选→搜索清空→个人批量隐藏→恢复；播放期间移入回收站→停止播放→保留对比面板→导出排除；Bob 恢复 Alice 删除的文件→保留目录、双方标注和音频哈希；损坏共享记录→失败保留选中项→修复记录后显式重试；重启；另存独立副本保留回收站和本人数据。
- 截图和矩形断言验证批量操作条、临时成功提示不重叠；目录计数对应当前视图结果。
- 兼容性：由实际 0.7.2 E2E 程序创建项目、身份、带备注标注、暂存屏蔽和 +20 dB 监听，再用 0.7.3 打开同一项目和本机数据目录。各数据保持一致，音频 SHA-256 不变，读取旧项目不自动生成回收站文件。

## 验证边界

双客户端在同一台 Windows 电脑通过同一测试目录协作；未进行两台物理电脑的 NAS 断网实测。错误重试使用测试专属共享记录的损坏注入，并验证失败不覆写该记录。旧客户端不认识回收站，参与协作的客户端需统一升级到 0.7.3。回收站不释放音频磁盘占用，本版本没有永久删除入口。
