# 0.7.1 更新验证记录

本次按用户要求直接更新主分支，没有新增规格审批、工作树或评审流程。更新基线为 `6b5e16b56e5d5a10479254054880bcd2c2273912`，交付为覆盖原程序目录的 **0.7.0 → 0.7.1 更新 ZIP**。

## 改进与兼容性

- 播放栏直接输入选区增益，回车或 ✓ 应用；可撤销，不修改原音频。监听增益也有直接输入框，保留全局及跟随设置。
- 首次播放无需右键即可出现默认起播虚线；切换列表音频时播放源同步切换。
- 上下键切换音频，避开输入、菜单和对比另一侧正在显示的文件；左栏宽度可拖动并记忆，右键可复制原文件名。
- 类别提交等待确认期间防止重复提交；在串行队列的最新状态中检查重复类别，避免无效类别命令阻断后续导入。真正失败的修改仍需显式重试或放弃。
- 项目 3、协作 5、作者图层 2、私人工作区 2、交换包 4、DSP 2、目录组织 1、媒体目录 2、分析 1 的格式版本不变；应用标识和用户数据路径不变。不需要迁移、重新导入音频或重建身份。
