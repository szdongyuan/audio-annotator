# 0.7.2 验证记录

本次直接更新基于 `5a98478340076d1fc5d5735740d595d522b1b13d`，按用户要求沿用兼容更新方式。没有修改 Rust 业务逻辑、原生 IPC 结构或项目/作者图层/私人工作区格式。现有 0.7.0、0.7.1 数据无需转换。

## 行为

- Delete 删除选中的已有标注框；临时选区按 Delete 创建屏蔽。输入框、菜单和对话框保持原有键盘行为，按键重复不会重复提交。
- “标注与属性”的八个标签固定为两行，作者列表及其他长内容独立滚动，不再挤压标签栏。
- “全局设置”存储在本机 WebView 的 `audio-annotator.global-settings.v1` 中，包含播放、显示、分析参数及按项目/音频区分的例外。应用到全部音频会重置对应例外，切换音频、项目与重启后继续生效；不修改共享作者图层。
- 全局分析参数按需同步到当前可见音频的本机分析状态；原生确认前，频谱继续使用已经确认的参数，不绕过原生的过期请求检查。
- 同事的已验证类别在分类菜单中可直接使用，同名类别优先复用自己的类别。首次使用不同类别时为自己的图层建立新 UUID 引用；他人的类别、标注和备注保持不变。
