# Default Collaboration Implementation Plan

> **For agentic workers:** REQUIRED: Use the `subagent-driven-development` skill to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the same author-isolated project the default for single-user and NAS work, without requiring account registration or a collaboration-copy step.

**Architecture:** Preserve per-author immutable publication and private workspaces. Add a versioned append-only media catalog and a DPAPI-protected stable local identity, then route normal create/import/save-as through this backend. Foreign catalog changes are explicitly adopted behind the existing save barrier rather than replacing live documents on polling.

**Tech Stack:** React/TypeScript, Tauri 2, Rust, Windows DPAPI using existing pinned windows-sys, Vitest, Rust integration tests, Selenium/tauri-driver.
