## Implementation choices

Retain the existing project/layer transaction routes. New display/session/filter choices are personal local records. Independent inspection uses owned transient native resources so its analysis/playback controls never change shared or main-workspace state. Evaluation/reannotation is outside this release; no link sidecar or export projection is needed.

## Compatibility / Migration

- Backward compatibility: required.
- Protected surfaces: existing project/author/catalog/organization/recycle formats, audio bytes, existing label UUIDs and ownership, private/global settings, normal save/recovery and existing export container formats.
- Allowed breakage: improved file-row geometry, automatic catalog visibility instead of manual-only adoption, Authors now includes self, optional startup restore prompt, list entries open a preview before explicit navigation.
- Migration strategy: none. Add separate versioned local UI/session storage; existing persisted document/layer schemas remain unchanged and readable. No automatic cleanup or modification of the user's real NAS project.
