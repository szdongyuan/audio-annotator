# 多标签、监听增益与紧凑编辑工作区

日期：2026-10-27。状态：用户已要求实施全部八项改进，并确认“监听全局默认、单音频绝对覆盖、恢复跟随”的方案；沿用无需逐次批准规格的自主实施授权。本文在已完成目录/导入/导出任务 1–4 之后增加编辑范围，最终桌面验收与 Windows 0.7.0 打包只执行一次。

## 1. 用户目标和边界

一个框选可以标多个标签。临时选区在外部单击一次后消失；普通左键单击应设置白色虚线和下次播放起点。监听有全局和单音频增益，区域也可执行增益编辑。屏蔽是可撤销的暂存处理，执行后不留下可抓取的“屏蔽框”。左侧列表紧凑，操作移到右键菜单；播放与增益/重置按钮紧邻频谱下方。必须真实模拟复杂连续操作，不能以独立按钮单元测试代替桌面验收。

继续支持 1–6 通道、双音频独立对比、协作按作者隔离标注、共享目录、ZIP/文件夹导入、保留或平铺导出。不开设录音、在线服务器、用户认证、防冒充、数据迁移或直接改写原音频。保留现有撤销/重做、生命周期、任务取消、未确认导入恢复、严格 IPC/文件校验和原始字节校验。

## 2. 三种增益/处理的语义

### 2.1 监听增益

“全局”表示当前个人项目工作区所有音频的默认监听值；不同协作者、不同本机工作区互不影响。默认 0 dB，每个音频的覆盖值为 null 时跟随全局。单独设置后使用该绝对值，不与全局相加。显式“恢复跟随全局”重新设为 null；手工输入与全局相同的数字仍属于显式覆盖。全局和覆盖均为有限数，范围 -60 至 +24 dB，可按 0.1 dB 输入。

共享项目通过已有本地个人工作区 preferences 持久化默认和按 media UUID 的覆盖；普通项目在当前 runtime 内也必须可用。普通项目不引入新的共享或项目文件字段来存监听偏好；其跨重启持久化不在本次范围。切换 runtime 时不得把旧项目的覆盖误套到新项目。删除/失效媒体的覆盖须有界清理，不能影响其他媒体。

监听增益作用于原音、处理后声音、文件和选区播放，位于暂存 DSP 与通道混合之后、设备样本格式转换之前。沿用独立的 0–1 输出音量，实际监听幅度 = 音量 × 10^(有效监听 dB/20)。处理/混合/环形缓冲保留有限浮点余量，不得在区域放大后、监听衰减之前先行截幅。最终设备输出限制到合法样本范围，不能溢出、产生 NaN 或整数回绕；不偷偷归一化原 PCM。实时标量通过不超过 10ms 的短幅度过渡避免突然阶跃，回调中不得引入锁、分配或 I/O。UI 区分监听增益与频谱显示增益。

播放中调监听增益使用 runtime/project/media/generation 绑定的实时输出标量更新：不重建 PCM、不重新开始或跳动播放位置、不改变选区/播放意图、不重算频谱、不产生文档历史。迟到的旧播放/旧 runtime 更新不能作用到新流。保存偏好与实时更新失败分别可恢复，不撤销已成功的另一侧。

### 2.2 区域增益

划选指定媒体、通道、时间和频段，在浮动选区操作/右键菜单或底部栏输入增益并显式“应用”。数值范围 -60 至 +24 dB，默认 0；0 dB 不创建无意义编辑历史。一次应用是一次可撤销的暂存编辑，不是监听偏好。成功后清除该临时选区，未完成/失败则保留可重试输入。若原选区对应已保存标注，保留标注本身和标签，取消选中即可；不得删除或改写标注。

在现有共用 STFT/iSTFT 处理器中实现，与屏蔽使用同样的时间/频率过渡权重。多个增益在同一时频点按加权 dB 相加，组合 dB 限定在 -120 至 +48 以保证有限输出；相同区域重复执行增益会累加，不能被掩码的几何去重算法吞掉。屏蔽抑制系数与增益相乘，因此完全屏蔽处始终为零。应用顺序对最终同组效果无影响。原音模式绕过所有暂存编辑，监听增益仍生效。

处理后频谱必须基于实际处理结果更新，不能只绘制色块假装修改。共用处理器、缓存键和处理版本必须完整包含操作类型/增益值/重复次数；仅修改监听值不能污染分析缓存。保留现有边缘平滑与 STFT 数值误差预算，不要求窄带边缘达到数学硬切割；区域内部屏蔽的显示仍按现有正确的置黑效果保留。

### 2.3 屏蔽

Delete、右键“屏蔽选区”和已有浮动动作均执行屏蔽，成功后清除临时选区。既有标注框继续存在但不再激活。频谱保留处理后置黑，声音对应频段被抑制；不渲染、命中、拖动或通过重叠对象菜单重新激活编辑框。编辑记录可在低频使用的处理列表检查、启停或移除，定位仅定位视图，不重建持久编辑框。失败不能假装成功清除选区，迟到完成不能清掉用户新画的选区。

“重置屏蔽”对当前操作音频的所有通道移除全部屏蔽记录（包括禁用记录），一次撤销可全部恢复；不清除区域增益、标注、其他音频编辑或监听偏好。无屏蔽时禁用，不产生空历史。区域增益的移除仍在处理列表/撤销中进行，避免“重置屏蔽”暗中重置别的处理。

## 3. 多标签

区域标注、整段音频与单通道均由单一 nullable categoryId 改为 categoryIds 集合；通道为 channelCategoryIds: string[][]，长度严格等于通道数。空集合表示未分类；标签 UUID 必须存在于同一作者的 categories，无重复，数组保留已接受的稳定顺序；每目标最多 64 个标签且不超出当前类别集合。删除类别只移除该 UUID，不能丢失其他标签或备注。

区域属性、文件/通道入口、选区浮动按钮、右键及主菜单均能连续勾选多个标签，已选项可再取消；“清空标签”一次清空。勾选菜单保持打开，Escape/点外部关闭并正确还焦点，键盘 Space/Enter 可切换，checked/disabled 状态有可访问语义。快速连点标签使用串行队列中的最新状态合并意图，不能把别的刚选标签覆盖。将临时框首次标注为多标签时只创建一个标注，后续勾选更新该标注；不能每个标签创建一个重复框。

多标签名称在框旁和列表中紧凑连接并可通过 title/属性查看完整值，不增加说明条；框只描边、不填充。颜色采用该作者类别定义顺序中首个已选标签的颜色，空集合用默认描边，不随着勾选顺序随机变化。列表筛选任一匹配标签，参考/使用数量按对象计数，不把多标签对象统计为多份区域。未分类筛选仅匹配空集合。

共享层继续只包含该作者的类别、文件/通道分类备注和标注，不含监听、增益、屏蔽、视图或混合。对方的全部标签可显示和检查但不可修改。复制、SaveAs、导入/导出保留当前作者完整多标签与目录；原有作者 UUID/不覆盖他人/本地草稿隔离不变。

## 4. 点击、框选与游标

保持现有超过 4 CSS px 才算拖动、Alt+左键/中键平移、边/角缩放、激活选区内部抓取的优先级。空白处左键单击（按下与释放未跨拖动阈值）清除临时框，并在点击的精确时间设置当前音频白色虚线和下次自动播放起点；一次点击完成两件事。已保存框只取消激活，不删除。无选区时同样设置游标。

激活选区外的首次手势不直接另画框，沿用先解除激活的 Adobe 风格；该手势释放后临时候选必须真正清空，不保留需第二次点击才能消失的暗框。随后新的拖动可画选区。该解除手势如果超过阈值不当作普通单击移动游标。点击/拖动激活选区内部仍选择/抓取，不能误设游标；拖框、拉标尺、平移、菜单/按钮操作均不能误跳定位。点击另一个已保存框可直接选择它。

白色虚线按 media UUID 保存当前 runtime 的 cue，两通道/多通道同一音频对齐；另一对比音频的 cue 不改变。存在激活选区时默认播放选区；空白点击已将其解除后默认从 cue 播放。点击定位后不得沿用旧的 paused/resumable 意图从旧点恢复；下一次播放必须采用新 cue。正在播放时，在同一播放音频上的普通点击只更新下次起点，不停止或重新配置当前播放；随后停止/再次播放采用新 cue。实际交互另一音频的频谱仍沿用既有切换播放源的停止/重置合同，不自动开始该音频；面板选择器、设置等控件不能暗中切换播放源。右键点击位置播放的既有功能继续工作。

## 5. 布局和重置

左侧媒体由多行卡片改为 26–30 CSS px 单行列表，与目录行一致；图标、主名称及必要的简短状态即可。采样率/时长/通道/标签/完整来源放 title 或右键“属性”/已有属性区，隐藏、移动、关联操作移入右键菜单，不在每行显示多排按钮。保留目录树、搜索、计数、隐藏恢复、错误状态可达性和键盘操作。长路径省略但可区分同名来源。

播放栏置于中央频谱工作区下方且紧邻频谱，宽度随中央栏变化，不横跨左右侧栏。单文件和双音频使用一条共享栏，作用于最近交互的操作音频（播放源）；栏中用紧凑名称/tooltip 明确目标。对比面板选择器、设置、侧栏操作不能暗中切换播放源。

包含停止、播放/暂停、循环、时钟/位置、播放原音/处理后切换、输出音量，以及监听增益（全局/此音频目标选择、数值、恢复跟随）、区域增益入口、重置视图、重置屏蔽。无录音。窄窗口优先保留播放/停止/时钟，低频区域增益和重置动作收进同栏溢出菜单；增益输入可置于同栏锚定的小浮层，禁止为解释占用固定整行。按可用宽度布局，不挤成不可点击的小控件。

重置视图恢复操作音频的 [0,duration] 时间与 [0,Nyquist] 频率范围；保留频谱 STFT/Mel、win/hop、配色、显示增益、动态范围、轴混合和可见通道、选择/标注/DSP状态。启用联动时间时遵守既有联动合同更新另一侧时间，频率不联动；不切换媒体。reset/批量移除遵守已有队列和草稿提交，不跨 runtime 使用迟到回调。

1000×680 与常用较大尺寸必须无页面水平溢出；双文件/1–6 通道沿用可滚动最小频谱高度，新增栏不侵占到不可读。菜单/浮层 Escape/点外关闭、滚动可达、焦点恢复；已有分析设置弹窗规则不退化。新 UI 不增加永久操作说明条。
