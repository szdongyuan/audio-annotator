# 频谱清晰度与选区工作流修正 · 0.2.1

状态：用户于2026-10-23明确“可以，首先实施这些改进”，批准本方案及下述追加要求，执行前合并复审。产品基线：`d988380930c09a7bf1c81ad6dc8567d98b14f87a`（0.2.0）。

## 1. 用户要求与已确认决定

- 修正上一轮截图暴露的频谱清晰度问题；不能用低分辨率放大得到的性能成绩代表清晰绘制。
- 分析设置等非阻断浮窗点击外部应关闭。
- 双文件对比切换一侧音频时，另一侧文件不变。
- 用户确认禁止两侧重复选择同一音频；发生重复选择时，高亮已显示该音频的另一侧，清楚告知原因。
- 当前选区旁直接提供悬浮“播放”和“标注”按钮，保持紧凑，不增加常驻说明条或工具模式。
- 屏蔽后的真实暂存处理结果显示在频谱中，可撤销；原始音频不改写。
- 激活选区优先作为默认播放范围，框内部可拖动移动；点击选区外空白取消激活后再重新框选。
- 频谱右键处显示白色竖向虚线，提供“从此处播放”，与“播放选区”明确区分。
- 分享默认完整包（含音频）；仅标注文件保留为次要选项；“另存为”改名为“另存项目副本…”，保留本机分支工作副本用途。
- 沿用用户明确的无迁移要求；本轮不引入旧格式兼容或迁移流程。

## 2. 已定位的问题

1. `SpectrogramCanvas.tsx`用`min(DPR, 1024/width, 256/height)`限制整幅位图。800×600 CSS绘图区实际只有341×256，再由CSS撑满；高度限制还连带损失时间轴像素。
2. `renderer.ts`把屏幕频率取整为最近FFT bin、时间向下取整为最近帧，再做颜色映射；展开低频时会出现重复行和阶梯边缘。
3. `AnalysisSettings.tsx`没有外部点击或Escape关闭处理。
4. `useWorkspace.ts`在所选文件等于对比文件时主动交换两侧；`CompareWorkspace`又直接用媒体列表选择决定主面板，不能保持稳定的面板身份。
5. 当前选区已有共享播放、分类和生命周期校验，但没有直接可见的悬浮入口。
6. 分析目前固定从原始PCM读取，屏蔽仅用于试听；播放模式手动区分原音/处理后/选区，激活框不会自动成为默认播放范围。
7. 导出完整ZIP确实包含全部原音频，但UI默认选择仅标注JSON，容易造成分享预期错误。

仅凭截图不能判断Audition的窗长、FFT、hop、轴范围与色阶。修复不得声称已经复现其私有渲染或保证截图逐像素相同。

## 3. 方案比较与建议

推荐：保留现有React/Canvas/Rust分析链路，修正实际像素分配与显示采样；为对比建立明确的面板目标；浮窗和选区按钮复用既有生命周期与动作。

- 只调颜色、FFT默认值或扩大窗口：改动小，但绕不开256像素硬限制，也不能修复两侧交换；不采用。
- 当前链路定向修复：复用已验证的音频、保存与缓存逻辑，增加可测的显示质量合同；采用。
- 全面更换WebGL/分析引擎：改动与验证范围较大，本轮没有必要；不采用。

## 4. 频谱显示清晰度

### 4.1 实际像素与预算

- 正常稳定状态下Canvas backing size为绘图区CSS尺寸乘实际DPR，取整误差不超过1像素。移除固定256高及由它造成的宽度缩减；DPR变化、面板大小变化、侧栏开合、比较分隔调整后重新分配。
- 验收尺寸为真实外窗1280×800、1920×1080，另用隔离WebView覆盖DPR 1、1.25、2；不得将模拟DPR称为实际Windows系统缩放测试。
- 继续使用共享数值缓存和可复用栅格缓冲，显示缓冲按整个工作区统一计量；保留64MiB数值缓存和32MiB栅格工作预算。实现必须计入自身保留的RGBA缓冲，不能只检查单张图片尺寸。
- 视口外通道可以释放高分辨率缓冲，滚动进入后重建；不得清除其标注、视图或分析身份。普通验收尺寸必须达到实际像素，不得通过静默低清降级通过性能测试。
- 超出显示预算的极端尺寸使用明确的资源限制反馈，不无限分配；上述普通验收尺寸与两文件各6通道滚动必须正常工作。

### 4.2 采样与颜色

- 依据实际时间/频率位置取样。像素小于数据间隔时，在相邻帧/频点间进行显示插值；在功率域计算权重、转换dB后再映射颜色，避免对已着色图片加模糊或锐化滤镜。
- 分块边界和频率分区之间使用真实相邻样本；没有邻居时按有效端点处理，不能与黑色/零值虚构插值。不得在音频尾部空白区绘制不存在的数据。
- 取样位置固定如下，图像、刻度、标注仍共用同一物理坐标。屏幕像素在`x+0.5/y+0.5`处反算真实秒/Hz，保持坐标误差≤0.5 CSS px。
  - 原始时间帧`j`定位于`j × hopSize / sampleRate`，沿用现有窗起点语义，不额外平移半个窗长。短尾帧的分析零填充不改变该时间锚点。
  - 时间LOD输出行`r`包含从`f = startFrame + r × 2^timeLod`开始的`n = min(2^timeLod, sourceFrames - r × 2^timeLod)`个真实帧，其平均功率定位于这些帧起点的均值：`(f + (n-1)/2) × hopSize / sampleRate`。不足整组的尾行使用实际`n`，不按完整stride虚构中心。
  - STFT原始bin `k`的中心为`k × sampleRate / fftSize`。频率LOD列`c`从`k = frequencyStart + c × 2^frequencyLod`开始，真实bin数为`n = min(2^frequencyLod, frequencyCount - c × 2^frequencyLod)`；代表频率为`(k + (n-1)/2) × sampleRate / fftSize`。
  - Mel原始band `k`使用已校验的native `melPointsHz[k+1]`作为中心；频率LOD组的代表位置取组内实际band中心的算术平均，与既有等权band功率平均相配，不把Mel band序号当线性Hz。
  - 在上述代表位置间，分别按真实秒与真实Hz计算线性权重，进行可分离的双线性功率插值。输入tile dB按`10^(dB/10)`恢复功率，插值后用既有dB下限转换；不对颜色或dB直接取平均。
  - 补齐跨tile/分区插值所需的相邻真实样本；邻居尚未就绪属于分析未完成，不能当全局端点声称最终绘制已完成。只有数据全局端点允许常值延伸，且严格限于`0 ≤ t < duration`、`0 ≤ Hz ≤ Nyquist`；文件尾部之外保持空白。不同LOD的数据使用各自上述真实代表位置，不按等宽格子拼接。
- 用户现有分析参数、幅度归一化、源音频、标注秒/Hz、DSP处理保持不变；显示插值不会制造新的分析分辨率。本轮不盲目增大默认FFT或改变窗长/hop。
- 现有Rust缩略层的功率平均保持数学语义；显示计划按实际绘制宽度选择所需时间细节，避免仍以1024像素作为所有窗口的隐含上限。在预算内复用已有更细数据，不因调色/轴混合重算同一份FFT。
- 保留当前色表与增益/动态范围控件；此次不宣称现有近似色表已精确校准为Audition。验收将像素、分析参数、轴和色阶分别记录，避免用增益变化冒充细节恢复。

### 4.3 暂存编辑的真实频谱

- 默认展示“暂存编辑”版本；没有启用屏蔽时等同原音。“原始音频 / 暂存编辑”是工作区统一的声音版本选择，同时决定普通播放及两侧频谱显示，不改变两侧文件身份。原有“旁路”语义归并到原始音频，避免两个相互矛盾的控制。
- Delete/屏蔽动作提交后，受影响文件的频谱由实际处理后PCM重新分析；不是给框涂黑，也不是仅隐藏原谱像素。禁用、删除、移动屏蔽或撤销/重做后刷新对应结果。原始版本仍能随时查看和试听。
- 复用Rust `audio::DspProcessor` 的Processed模式、相同DSP版本、时间/频率淡变与OLA算法；显示分析输入是原采样率、未混音、未设备重采样、未乘播放音量的各通道处理结果。临时试听选区的裁切/频带隔离不改变全图。
- 任意窗长的分析读取须拆成最多4096帧的处理块；沿用随机访问及全局窗对齐，保留必要halo，不从文件开头重放，不创建完整长音频内存副本。取消在各有界读取之间生效，遵守现有后台任务并发和PCM预算。
- 原始/处理后tile身份明确分离：源指纹、分析配置、处理版本、该文件启用屏蔽的几何签名及声音版本进入缓存/请求校验。签名由权威文档推导；改备注/类别/其他文件不能错误刷新本文件处理结果，编辑后旧结果不得盖回新图。未改变算法的旧原始tile可复用或自然失效，缓存不需要迁移。
- 处理后计算进行中使用已有局部进度/错误反馈，不能把旧图标为最新完成；新版本未完成前可保留旧图，但需明确“更新中”。失败保留编辑记录并提供重试，不回滚已接受标注命令，也不静默改回原音。
- 源文件字节和指纹始终不变。暂存指非破坏性编辑，不是关闭即丢弃：屏蔽记录随正常项目保存/分享，接收方可禁用或删除屏蔽恢复原音。
- 新项目/重开/分享导入默认暂存编辑；声音版本选择仅为当前会话状态，不新增文档字段。完整包保留原件及编辑记录即可重建同样结果；不要求跨机器复制本地撤销栈或分析缓存。

## 5. 浮窗关闭

- 分析设置点击浮窗外部或按Escape关闭；内部输入、拖动滑块、选择原生下拉选项不误关闭。
- 从浮窗内部按下、在外部释放的拖动不视为外部点击。关闭浮窗的点击不得穿透为画框、删除或播放操作。
- 打开同一设置按钮可再次关闭；点击另一文件设置可直接切换到该文件。处理打开事件与外部关闭的顺序，避免刚打开立即关闭或旧浮窗重新打开。
- 显示参数沿用立即生效；计算参数仍须“应用分析参数”才提交。关闭时丢弃未应用计算草稿，保留已应用设置，与原“关闭”按钮一致，不隐式提交无效参数。
- 保留明确关闭按钮，键盘关闭后焦点回到触发入口。项目替换、目标文件不再显示或被删除时关闭旧浮窗。
- 右键/主菜单沿用其已有外部点击关闭；帮助等纯查看浮层也支持外部关闭。删除确认、未保存错误、恢复决策、正在进行的系统文件选择器不做隐式确认或放弃。

## 6. 双文件独立切换与重复提示

- 两个位置分别为主面板和对比面板，身份随左右/上下布局保持稳定。每个面板标题提供紧凑文件切换入口，不另加一行设置。
- 切换入口只修改其所属面板。移除自动交换逻辑，任何入口都不能顺带把另一侧改成旧文件。
- 侧栏仍用于选择主面板文件；对比面板用自己的标题入口或“视图→双文件对比”指定。点击/标注右侧只改变当前操作上下文及播放源，不改侧栏或左侧文件。
- 若A/B正显示，左侧选择C得到C/B；右侧选择C得到A/C。若左侧选择B，则仍是A/B：对B所在的右侧面板做约1.2秒边框高亮，并在该面板标题附近短暂显示“该音频已在这一侧显示”。反向同理。
- 重复操作不写入视图草稿、不产生撤销项、不改变播放源或选区；选项可见并允许触发上述解释，不使用无原因的禁用选项。提示支持屏幕阅读器、减少动画偏好；高亮不改变频谱颜色。
- 所有切换入口共用校验：面板标题、侧栏、顶部对比菜单以及恢复后的状态。异步更新执行时重读另一侧，不能根据过期ID做重复替换。
- 时间轴联动只同步时间视口，不改变文件身份。切换文件后按现有联动规则更新目标范围，另一侧的文件、分类、备注、分析参数仍保留。
- 切换实际被替换的面板后，清除属于离开文件的临时选区/浮窗；另一侧有效选区不因主面板改变被无条件清除。按现有规则保留每个文件的显示参数和标注。
- 删除媒体、undo/relink、保存重开及项目替换必须保持两个不同有效文件或合理退回单文件；不得保存两侧相同的非法状态。

## 7. 激活选区、播放与悬浮操作

### 7.1 激活与抓取

- 全工作区最多一个激活选区。画框完成自动激活；临时框不持久化，已保存标注/屏蔽仍以稳定ID对应权威几何。
- 激活时，左键拖动框内部或边框均移动该选区，控制点优先resize；不在框内部创建新框。Alt+左键/中键仍优先平移。
- 点击激活框外的频谱空白取消激活，该次指针手势只取消激活，不同时新建框。之后下一次拖动可重新框选；单击另一已有对象可以直接切换激活对象。
- 未激活的临时框可保留一个轻量轮廓，隐藏控制点和悬浮条，不用于播放/快捷键；单击该框重新激活，无激活框时拖动则新建并替换临时框。取消激活不删除标注/屏蔽，也不禁用屏蔽效果。
- 菜单、按钮、侧栏等非绘图区点击不作为空白取消动作。Escape先关闭菜单，再取消手势（恢复原几何），无手势时取消激活。切换项目、删除目标或替换其所在面板清理失效选区；另一侧有效选择保留。
- 有效激活选区才响应Delete屏蔽。移动/resize的持久编辑在手势结束提交，拖动期间不反复写命令；继续校验运行态和旧几何，取消不得复活过期对象。

### 7.2 悬浮操作

- 存在当前激活的有效临时选区、已保存标注或屏蔽时，贴近其可见部分显示一条紧凑工具条：`播放`和`标注 ▾`。不要求鼠标恰好停在按钮上才出现。
- 默认在选区上沿外侧；顶部空间不足则移到可见范围内的合适位置，水平钳制在所属绘图区内。小选区不撑大矩形；选区完全离开可见范围或通道隐藏时不显示。
- 正在画框、移动/resize、平移时暂时隐藏，手势结束后更新位置；缩放、轴混合、滚动和窗口变化后跟随实际坐标。右键菜单或阻断对话框打开时不抢焦点。
- “播放”一键播放当前通道和时间/频率范围，沿用工作区声音版本；旁边的小菜单明确命名为“试听选区原音”和“试听选区（应用屏蔽）”。这些是本次试听的显式覆盖，不偷偷更改全工作区版本。源缺失/未就绪时禁用播放并提供悬停原因。
- “标注”直接展开项目类别和“未分类”。临时选区创建一次标注并绑定新ID；已有标注更新类别；屏蔽可按现有语义创建独立标注。复用右键共享动作，不复制持久写入逻辑。
- 工具条点击不触发画框、移动或清除选区；支持Tab、Enter、Escape。操作前复核项目运行态、当前对象ID和最新几何，避免菜单打开后目标变化产生错标/错播。
- 保留右键的备注、屏蔽、删除、放大功能及Delete屏蔽快捷键；工具条不替代这些已有入口。无有效选区时无空行、占位面板或教学文案。

### 7.3 默认播放与明确覆盖

- 空格、底部播放及普通顶部播放命令，在开始新的播放时优先使用激活选区的文件、通道和物理范围；没有激活选区才按当前播放文件、定位点/播放位置播放。无需额外切换“选区模式”。
- 正在播放时普通播放键为暂停；同一范围与声音版本未变时再次按键继续。创建/移动/取消激活选区时停止旧范围，不自动开始新声音；下一次播放按新状态配置。打开普通菜单不会停止现有播放。
- “播放整段”以及下节“从此处播放”是显式覆盖当前选区的本次播放意图，选区本身保留；暂停/继续保留本次覆盖，停止/自然结束后下一次普通播放重新遵从激活选区。不能用自动范围effect立刻覆盖显式命令。
- UI将“声音版本”和“播放范围”分开表达，不再把“原音/处理后/选区”放在同一个互斥下拉框。范围由激活状态自动决定，必要状态用现有紧凑控件表达，不新增常驻教学条。

### 7.4 右键定位与白色虚线

- 在有效频谱右键时记录该文件和真实时间位置；同文件可见通道显示1 CSS px白色竖向虚线。它是固定起播定位线，现有播放进度线另行移动；pointer-events为none，不阻挡框选/控制点。
- 菜单始终提供“从此处播放”；存在激活选区时另外保留“播放选区”相关动作，两者不能混为同一项。右键本身只定位/打开菜单，不自动seek、停止或启动设备。
- “从此处播放”选择点击所属文件，从定位时间到文件末尾，按文件原有通道混音和当前声音版本播放；点击的纵向频率不暗中变成带通范围。该命令显式覆盖当前选区，仅在实际执行时切换播放源。
- 捕获稳定运行态、mediaId与秒数，执行前重查源是否存在/可播放；联动短文件尾部空白或无有效后续样本的位置不允许执行，避免把空白点击夹回错误时间。
- 定位线随缩放/平移按秒定位，离开视口隐藏；比较的另一文件不凭空新增定位线。每个文件可保留自己的最近定位点，替换项目/删除文件清理，重开无需恢复。
- 普通播放在无激活选区且已停止时可从当前文件定位点开始；显式“从此处播放”的循环仍沿用已有全文件循环语义，不引入新循环范围模型。

## 8. 分享与本地副本

- 分享默认选择并优先展示“完整项目包（含音频）”，`.audioproj.zip`包含全部原始音频、三层分类/备注、区域、屏蔽记录及既有项目设置。对方用本软件导入即能继续，不需要另找原件。
- 保留“仅标注（不含音频）”作为次要选项，明确接收方需要同一批音频。维持源指纹校验、独立项目导入、路径脱敏、限额、取消及原子发布；不能悄悄漏掉缺失音频宣称完整导出。
- “项目另存为”改为“另存项目副本…”，保留既有在新目录创建工作副本并切换过去的语义，不承诺复制所有原音频。需要跨电脑使用的入口是完整包。
- 保存与分享必须排空已接受的屏蔽/几何编辑；导出期间显示重算可继续，但包内记录以同一已保存修订为准。接收端根据原件+屏蔽记录重建暂存编辑频谱，无需打包派生PCM或tile。

## 9. Compatibility / Migration

- Backward compatibility: partial。
- Protected surfaces: 当前v2文件结构、源音频字节、物理标注、三层分类/备注、屏蔽、可靠保存/恢复/锁/撤销、分享语义及1–6通道。
- Allowed breakage: 删除两侧自动交换行为；浮窗外部关闭；清晰绘制与暂存编辑频谱；激活框内部从新建改为抓取；播放范围自动选择；默认完整分享及另存文案。内部IPC/tile协议可明确改版，但不改变文档formatVersion。
- Migration strategy: none。继续明确拒绝v1/未来未知格式，不新增数据库迁移、旧数据转换或专用迁移备份。

## 10. 验收与交付

1. 单元/组件红灯复现256上限、分析浮窗外部不关闭、A/B交换问题；加入实际按钮交互的回归，再验证修复。
2. 频谱使用稳定的多音、扫频、短脉冲fixture，记录相同参数下的旧/新显示。检查真实backing尺寸、细线/脉冲位置、跨tile接缝、尾部空白和非线性坐标；不得只比较DOM面板高度。
3. 原生桌面验证DPR、单文件双通道、双文件四图及6+6滚动；当前选区工具条靠边、小选区、滚动、移动/resize、分类和实际原始/处理后播放。
4. 真实pointer验证浮窗外部/Escape、内部拖动、原生下拉、不同文件设置切换；关闭点击不在底层创建选区。
5. 使用至少三个文件测试A/B→C/B、A/B→A/C及双向重复选择高亮；覆盖侧栏和顶部菜单、联动、保存重开、另一侧选区保留和失效目标防护。
6. 双音/脉冲输入验证屏蔽后实际处理PCM的谱能量下降及未屏蔽部分保留，截图与数值对照；禁用/删除/移动/undo/redo、原音切换、迟到旧tile、保存重开和完整包导入恢复一致。频谱分析与播放复用同一处理器，原音哈希不变。
7. 激活后空格默认选区、框内抓取、框外首次点击取消激活、再次拖动新建；暂停/继续、显式整段/起播覆盖及停止后恢复自动范围均测试。白色虚线按真实秒定位，菜单目标过期、短文件空白、不同DPR和缩放验证。
8. 分享默认完整包、两种格式语义、“另存项目副本”继续切换会话；完整包在原路径不可用的独立导入目录中仍能重建音频及屏蔽频谱，不只是检查ZIP文件名。
