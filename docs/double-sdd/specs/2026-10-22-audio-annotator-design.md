# 音频频谱标注桌面软件：首版设计规格

日期：2026-10-22

状态：用户已批准产品设计；独立规格审查 PASS（2026-10-22）；用户已确认书面规格（2026-10-22），可进入实施计划。

## 1. 产品目标与已批准边界

构建可持续迭代的 Windows 音频标注桌面应用，采用 React + Tauri + Rust。主要用途是查看频谱、对比音频、定位异常、为异常区域分类及备注，并通过文件交接标注成果。交付的是可安装运行、真实读取和播放音频、可靠保存数据的应用，而非静态页面或模拟分析演示。

用户明确选择：本地项目和文件分享；主要处理约 10 分钟以内、44.1/48 kHz 的短音频；1–6 通道；Windows；频率轴既能在线性和对数之间连续过渡，也能连续缩放和平移。

首版包括：STFT、梅尔频谱、多通道展示、最多两文件同时对比、区域标注、自定义类别、音频与通道备注、原音和频段试听、可撤销频段屏蔽、项目保存恢复及分享导入。

首版不包括：账号和服务器、多人实时编辑、团队权限和审核流、自动异常识别、剪切拼接、完整混音工程、处理后音频导出、其他操作系统的交付验证。项目可以包含多个音频，但分析区最多同时打开两个。

10 分钟与 44.1/48 kHz 是首版验收基准，不是静默截断上限。对于解码器支持的其他时长或采样率仍按实际信息处理，并提供取消和资源错误反馈；超过 6 通道明确报告当前不支持，不静默丢弃或下混后冒充原始通道。

## 2. 技术路线和责任边界

选择 React 界面 + Rust 原生音频核心 + Tauri 命令与事件桥接。相较于主要在前端解码计算，这一路线把多通道解码、分析缓存和播放生命周期集中在原生侧；相较于首版引入云端，它满足已批准的离线交付范围。

- React/TypeScript：布局、交互状态、频谱绘制、坐标映射、标注覆盖层及属性表单。采用 Canvas/WebGL 等适合大量像素的绘制方式，不以海量 DOM 元素绘制频谱。
- Rust 音频域：格式识别、解码、媒体元数据和内容指纹、分块采样访问、STFT/梅尔计算、暂存屏蔽处理及播放。
- Rust 项目域：持久化、文档校验、原子写入、恢复副本、分享包导入导出及路径管理。
- Tauri 边界：类型化命令结果和事件，明确项目、音频、通道、任务及版本标识；不通过 JSON 反复传送整段多通道 PCM。

原生侧维护有效的项目文档和递增 revision；前端通过带预期 revision 的变更命令更新，返回成功后再视为已保存到内存。过期变更拒绝并要求刷新，不静默覆盖。文本编辑可短暂保留本地草稿，失焦、切换项目和退出前提交。

模块划分为媒体导入、分析任务与缓存、视图坐标、标注及类别、播放与暂存编辑、项目存储、交换格式。模块边界通过媒体 ID、通道索引、秒、Hz 和分析参数交流，不传递 UI 像素作为业务数据。

## 3. 信息架构与视觉设计

默认中文界面、深色背景、清晰字阶和克制的强调色。频谱默认黑底、紫红到橙黄的渐变，视觉参考 Audition；不复制其商标、图形资源，也不声称与其未公开色表逐值一致。

主窗口分区：

1. 顶部：项目名称、保存状态、文件操作、单文件/双文件切换、选择/标注/屏蔽工具。
2. 左侧可调整宽度且可折叠的音频列表：名称、通道数、时长、标注数量、搜索和筛选。
3. 中央分析区：文件标题、通道选择、时间刻度、每通道频谱、频率刻度、播放指针、色阶参考及标注覆盖层。
4. 右侧可折叠属性区：区域属性、标注列表、音频备注、通道备注和类别管理，不在频谱上堆叠长表单。
5. 底部固定播放条：播放/暂停、停止、时间显示、定位、循环、音量、试听模式、独听/静音入口。
6. 独立分析设置面板：窗函数、窗长、hop、FFT 长度、梅尔频带数、颜色、显示增益与动态范围。

在 1280×800 窗口下主要操作可达；窄空间优先收起侧栏并让通道区纵向滚动，不把所有通道压成无法操作的细条。颜色之外以文本、边框和状态提示区分类别与选中状态。基础控件支持键盘聚焦、可读标签和快捷键提示；输入备注时不触发播放等全局快捷键。

空项目提供导入入口；计算中显示进度和取消；缺失音频、失败及恢复状态有明确页面状态。首次启动不假装已有用户数据。

## 4. 媒体导入与多通道工作区

输入支持 WAV（PCM 16/24/32 bit、float32）、FLAC 和 MP3。多通道主要由 WAV/FLAC 提供，具体以文件实际通道数为准。拒绝损坏、空数据或不支持的编码时说明是哪一文件失败；批量导入的其他有效文件仍可继续。

每个媒体保留原始采样率、帧数、时长、通道数和可用的通道布局信息。界面以通道 1–6 显示，内部使用从 0 开始的稳定索引，不擅自猜测未知的扬声器位置。原始文件只读，不写回编辑结果。

单文件默认展示前两个通道，单声道展示一个；用户可选择任何通道并展开全部通道纵向浏览。同文件所有通道共享时间窗口、播放定位和时间缩放；备注、标注和屏蔽按各通道独立保存。频率窗口与刻度参数在同文件通道间同步，避免比较时误读。

双文件模式上下排列两个文件面板，各自可选通道。时间轴默认独立，可开启联动；联动以文件起点为零、采用相同的秒范围和播放定位，不做内容自动对齐。短文件结束后的范围留空，不拉伸音频。频率轴按各自采样率的 Nyquist 上限处理，不伪造不存在的高频。两文件各自保留分析设置。

任一时刻只有一个文件作为播放源，点击面板或播放源控件切换；切换时停止旧源。单文件中支持单通道独听、通道静音和剩余通道混合。无可听通道时明确显示静音状态。

## 5. 频谱计算与坐标定义

STFT 初始参数：Hann 窗、窗长 2048 samples、hop 512 samples、FFT 长度 2048。支持 Hann/Hamming/Blackman/矩形窗；窗长是正整数，至少 64、不超过 32768 samples；hop 在 1 与窗长之间；FFT 长度为不小于窗长的 2 的幂，最大 65536。控件同时显示 samples 及按实际采样率计算的毫秒，非法组合在前后端均拒绝。

分析帧以 frameIndex × hop 作为起点，在文件尾部补零；短于窗长的非空音频仍有分析帧。时间标签和标注始终使用原始音频时间，不能因补零延长可标注范围。显示单边频谱，频率 bin 为 binIndex × sampleRate / FFTSize。幅度依据窗增益归一化，使用固定 dB 参考而非逐帧自动归一化；说明显示增益只改变视觉，不改变音量。

梅尔频谱由相同 STFT 功率计算得到，使用覆盖 0 到 Nyquist 的三角梅尔滤波组；初始 128 带，可选 32–512 带。梅尔定义为 2595 × log10(1 + f/700)，滤波组与归一化方式固定并写入分析算法版本。零能量通过明确数值下限转为有限 dB 值，不产生 NaN 或无穷值。

默认显示动态范围 100 dB，显示增益 0 dB；提供可编辑上下限或等效增益/范围控制及多套色表。相同显示参数对相同归一化强度使用相同颜色。STFT 幅度和梅尔带功率属于不同量，界面区分其尺度，不把它们的颜色解释为相同物理量。

STFT 频率轴混合参数 a∈[0,1]：0 为线性，1 为对数式，允许连续拖动。为包含 DC，使用归一化 log1p 变换：g(f) = (1-a)×f/F + a×ln(1+f/20)/ln(1+F/20)，F 为当前媒体 Nyquist，f 单位 Hz。视口对 g(f) 的可见上下界归一化；逆变换通过单调求逆。实现可优化，但不得改变这套映射语义。

频率轴缩放以鼠标位置为锚点，并保持合法频率边界；平移不超出 [0,F]。时间轴同理限制在音频范围内，双文件联动时允许显示最长文件范围。梅尔模式使用梅尔映射及频率范围缩放，不套用 STFT 的线性/对数混合滑块。

所有命中测试、框选、边界拖动与绘制共用正反坐标转换。标签保存秒与 Hz，切换窗长、hop、频谱类型、混合比例和缩放后不会改变其数据；只改变其可见位置和频谱细节。

## 6. 标注与类别

区域标注包含稳定 ID、媒体 ID、单个通道索引、起止秒、上下界 Hz、可空的类别 ID、备注、创建及更新时间。有效范围为 0≤start<end≤duration、0≤low<high≤Nyquist。拖动反向框选时自动归一化边界，零面积框选不创建记录。区域可以重叠。

首版每个矩形属于一个通道，最多关联一个类别；可以先保存为“未分类”再补充类别。选择工具负责选取、移动和边缘缩放，标注工具负责创建，屏蔽工具负责暂存编辑，三者有明确可见状态。

类别属于项目，具有稳定 ID、名称与颜色。名称非空，项目内去除首尾空格后不可重名。改名或换色自动更新引用；删除被使用的类别时提示受影响数量，确认后把相关区域设为未分类，不删除区域或备注。删除和相关更改支持撤销。

音频备注附着于媒体 ID；通道备注附着于媒体 ID + 通道索引；区域备注附着于区域 ID。三种备注不会相互覆盖，属性栏明确标注当前编辑对象。

标注列表显示类别、通道、时间及频率范围、备注摘要。支持类别、通道及备注文本筛选；点击条目选择目标通道并定位范围，但不自动播放。删除区域支持撤销。

## 7. 播放与非破坏性暂存编辑

提供播放、暂停、停止、拖动定位、音量和循环。时间游标以音频播放时钟驱动；播放结束停在末尾，停止返回本次播放起点。播放时允许浏览频谱和编辑备注。

试听模式：

- 原音：忽略全部屏蔽操作，播放当前可听通道。
- 处理后：应用已启用的屏蔽操作，可一键旁路。
- 选区：以当前选定区域的通道、时间和频率范围试听；循环仅循环该时间段，可分别试听原始或经过屏蔽后的选区。

选区试听属于频域带通重建，不是截取频谱图片。采用有重叠相加归一化的分析/合成链路，在时间与频率边界引入过渡以减少突变。未屏蔽的恒等链路应近似重建原音；不承诺任意狭窄频段无伪影。处理使用独立的稳定 DSP 参数，不随可视化 STFT 参数变化而改变已保存操作的语义。

屏蔽操作具有独立 ID、媒体和通道、时间/频率边界、启用状态与稳定的处理参数版本，和区域标注分开保存。多个屏蔽区域组合为抑制区域的并集，重叠不累计成额外增益或反转；边缘过渡也使用确定的组合方式。可禁用、调整、删除单条或整体旁路。

输出设备通常为双声道：单通道独听居中输出；立体声保留左右关系；3–6 通道在无可靠扬声器映射时按可听通道等权归一化混合后居中输出，界面说明这是试听混合，源数据保持原样。输出前保证有限数值并防止越界削波；设备采样率不同时在播放输出边界重采样，不改变分析与标注坐标。

标注、备注、类别及屏蔽变更支持会话内撤销/重做；视口拖动不进入内容撤销历史。重启后恢复当前内容，不要求恢复完整撤销栈。长文本以一次编辑会话或适度合并的变更作为撤销单位，不按每个字符生成一条独立动作。

## 8. 项目模型、保存与恢复

本地项目目录以版本化 JSON 文档作为权威数据，缓存放在单独的可删除目录。项目可引用外部音频；完整包导入后使用项目目录内媒体相对路径。保存字段包括：

- formatVersion、projectId、名称、revision、创建/更新时间。
- 媒体：ID、显示名、路径引用、原文件字节 SHA-256、字节数、采样率、帧数、通道数、音频备注、各通道备注。
- 类别、区域标注、屏蔽操作。
- 各媒体分析参数、播放混合选择、视图状态；缓存不属于权威内容。
- 分析及 DSP 算法版本，用于缓存失效和处理兼容。

本地文件路径不作为媒体身份；移动文件后可重新关联，必须核验指纹与音频元数据。校验尚未完成时显示校验状态，不提前宣称匹配。不同编码的同一段声音具有不同原文件指纹，首版不自动视为同一文件。缺失音频时仍能查看和编辑已有文字标注，播放与频谱禁用，提供重新关联入口。

变更后 1 秒防抖自动保存；持续操作时每 5 秒至少尝试保存当前一致快照。明确显示保存中、已保存、失败和未保存状态；保存时间只在磁盘写入成功后更新。手动保存、切换项目和正常退出会提交草稿并等待保存。

使用同目录临时文件、完整写入及原子替换，保留最近有效备份；加载时校验数据结构、引用和边界，失败时提供恢复有效备份，不把损坏文档自动覆盖为空项目。恢复副本与正式文件采用 revision 和校验信息选择，存在更新的有效恢复副本时由用户选择恢复或保留正式版本。

保存失败保留内存中更改，允许重试或另存。正常关闭时仍有未保存内容则提供重试、另存、放弃或取消关闭。缓存损坏可重算，不能导致标注丢失。一个项目只允许一个写入者；第二实例不得覆盖文件，可提示项目已被占用。

## 9. 分享与导入

提供两种交换文件：

1. `.annotations.json`：版本化项目交换文档，包含媒体描述与内容指纹、类别、区域、各层备注、分析设置和屏蔽操作，不含音频、不包含来源机器绝对路径。
2. `.audioproj.zip`：相同语义的清单 + 被引用的原始媒体文件，以媒体 ID 组织内部相对路径；不包含分析缓存、历史备份或临时文件。

导出使用一个一致 revision 快照；导出中途的编辑不会产生半旧半新的文档。导出失败不留下看似成功的最终文件；目标已存在时通过保存对话流程明确处理覆盖。

导入默认创建独立项目副本，生成新项目 ID，并一致保留/映射其内部媒体、类别和区域引用，不直接合并到当前项目。仅标注文件允许先导入后逐个关联音频；匹配失败明确报告，禁止把标注套到不同数据上。

项目包在暂存目录校验后再发布为新项目。检查版本、清单结构、引用、数值有限性、范围、媒体指纹、重复条目和解压路径；拒绝绝对路径、目录穿越和链接条目。对条目数及解压总量进行有界检查，读取媒体分块进行；失败不影响已有项目。未知的更高格式版本拒绝导入并说明需要更新程序，不忽略未知字段后静默丢失数据。

导出再导入后，除项目身份、路径和导入审计信息外，标注、备注、类别、媒体关联、分析参数和屏蔽语义应一致。

## 10. 任务、性能与错误处理

解码、指纹计算和分析在后台执行，UI 和音频输出回调不进行阻塞磁盘操作或完整 FFT 任务。采样访问和频谱按块管理，禁止为每次缩放重新生成整段全分辨率频谱；不同时保留全部解码 PCM 的多份内存副本。

缓存键覆盖媒体指纹、通道、算法版本、窗长、hop、FFT、窗函数及梅尔参数。颜色和频率轴变换在渲染侧完成，不重新执行 STFT。按可视时间窗口和分辨率请求 tiles，视口外工作低优先级，使用有界内存缓存和可失效磁盘缓存。

任务具备 ID、generation、进度、取消与错误。切换媒体或参数后取消过时工作，旧结果即使迟到也不能覆盖当前画面。参数滑块频繁变化采用短防抖或预览，避免无限排队。媒体在运行中被外部修改时使缓存失效并要求重新校验关联，不将旧标注无提示转移到新内容。

首版性能验收在当前 Windows 开发机记录 CPU、内存、音频设备与构建模式，采用 10 分钟/48 kHz/6 通道测试文件及两文件对比场景。目标：暖缓存平移缩放的可见反馈 P95 不超过 100ms；冷计算期间 UI 仍可操作，取消可见反馈不超过 500ms；播放无可重复的缓冲欠载。记录首屏分析耗时和进程峰值内存，不在未测量前宣称性能达标。若不达标，应优化或明确报告，不用缩小测试文件掩盖问题。

错误包含可读原因、受影响对象和可执行恢复动作。播放设备失败可重选/重试；解码失败不生成空成功结果；分析失败不删除已有标注；磁盘空间不足或无权限不显示已保存。日志不记录音频内容或整段备注。

## 11. 验收标准与验证方式

### A. 可运行交付

- 可在 Windows 上以开发模式和打包应用启动；验证正式构建路径，不把纯浏览器预览视为桌面验证。
- 提供构建/运行文档、依赖说明和可复现的检查命令。检查依赖许可证及分发要求，附必要第三方声明。
- 无必须联网的运行功能；安装时对 WebView2 等运行时依赖明确处理。

### B. 信号与坐标正确性

- 已知单音和双音信号的 STFT 峰值落在理论频率最近 bin；短文件、非整窗结尾、静音输入正常，无 NaN/Infinity。
- 梅尔频带响应符合固定滤波组定义；调窗长/hop 后帧数量和时间位置正确。
- 对线性、对数及多个中间比例，以及梅尔模式，坐标往返误差不大于 0.5 屏幕像素；切换视图不改变已保存秒/Hz 数值。
- 恒等重建在边界处理后相对 RMS 误差不高于 1e-4；选择与屏蔽测试使用双音信号，远离过渡边界的目标频率抑制至少 30dB，保留频率的幅度变化不超过 1dB。

### C. 真实用户流程

- 真实导入 WAV、FLAC、MP3，并验证 1、2、6 通道；通道索引正确，无串道。
- 同页观察两个通道和展开六通道；两文件独立/联动浏览、不同长度/采样率边界行为正确。
- 创建、移动、缩放、分类、备注、筛选、定位、删除及撤销；所有层级备注相互独立。
- 原音、处理后、选区、循环、定位、独听、静音和旁路实际可听；播放时间指针与声音一致。
- 实际执行 Windows 桌面交互验证并记录结果。合成信号数值测试不能代替设备试听；若环境缺少设备或自动化能力，明确标记未验证项。

## 12. Compatibility / Migration

- Backward compatibility: not required（当前为空项目，没有已有应用或历史标注文件需要兼容）；首个发布格式之后需要维护本产品数据兼容。
- Protected surfaces: 首版发布后的 JSON/项目包格式及其时间、频率、通道、媒体身份和处理语义；源音频字节不变。
