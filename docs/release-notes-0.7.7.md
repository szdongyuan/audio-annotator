# 0.7.7 测试版

- 可删除完全空的文件夹子树，或其中音频全部已进入共享回收站的子树。确认框说明文件夹数量、回收站音频数量及迁移后的目录归属。
- 删除只移除目录记录；回收站音频归属移到被删目录的上级，顶层目录则移到项目根目录。音频、原始文件名、标注、备注及回收站内容均保留，恢复后在新的归属目录显示。
- 隐藏、筛选掉或尚未加载，但未进入共享回收站的关联音频仍会阻止删除。提交时再次检查目录版本和当前回收站状态。
- 包含此前的目录导航、频谱切换及窗口响应修复，以及更紧凑的多层目录缩进。

现有项目、标注和共享目录格式不变，无需迁移。直接从 0.7.5 更新时也应使用完整安装包或包含全部资源的更新包。实际验证范围见 [验证记录](verification-0.7.7.md)。
