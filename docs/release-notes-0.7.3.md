# 音频标注 0.7.3

- 左侧紧凑音频列表新增多选、批量隐藏、批量移入共享回收站和批量恢复。
- 支持 Ctrl 多选、Shift 连选、Ctrl+A 全选当前筛选结果、文件夹半选状态。搜索和目录/筛选变化会清空选择。
- 筛选支持文件名或路径、我的标注状态和标签；高级筛选默认收起。
- 隐藏只影响自己的列表，可撤销或在“我的隐藏”中恢复；共享回收站对所有协作者生效。
- 回收站保留原音频、目录位置和各作者的标注/备注。本版本不提供永久删除。
- 文件列表焦点内 Delete 打开移入回收站确认；频谱选框和标注框的 Delete 行为保持不变。
- 删除/隐藏正在播放的来源时停止播放；双音频对比保留未受影响的一侧（有可替换文件时）。
- 批量操作原子提交，失败保留选择；共享冲突刷新后须核对并重试。近期相同操作的重试不会重复删除已被恢复的音频。
- 导出我的标注/项目包排除回收站音频；另存我的项目副本保留回收站状态及自己的数据。

## 更新与兼容

关闭软件后覆盖更新包，或使用完整安装包。原项目、音频、身份和私人设置保持原位，无需重新导入。

项目原有格式不变；首次回收操作会新增共享 `recycle.json`。所有协作者应更新到 0.7.3：旧客户端仍能读取原项目，但不识别回收站，会继续显示这些音频。不要手动删除共享项目里的音频或回收站记录。

共享回收站不会释放 NAS 音频占用的空间。个人隐藏设置在恢复回收站文件时保持原样，已隐藏的音频仍可在“我的隐藏”取消隐藏。
