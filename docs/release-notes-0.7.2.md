# 0.7.2

- 已保存的标注框选中后，Delete 删除该标注；临时选区按 Delete 屏蔽频段。支持撤销和重做。
- 右侧“标注与属性”的标签栏固定显示，作者列表及长内容独立滚动。
- 右上角新增“全局设置”：本机监听增益、输出音量、循环、声音版本、STFT/梅尔、线性/对数比例、显示增益、动态范围、色表及分析参数。全局设置在切换音频、项目与重启后保留，不写入共享标注或项目分享包。
- “应用到全部音频”使当前和以后打开的音频跟随全局设置，也重置先前的单音频例外。音频内“设置”及播放栏监听输入框仍可单独调整，并提供恢复跟随全局。
- 同事发布的类别可在区域、文件和通道分类菜单直接使用。使用时建立自己的类别引用，同名类别自动复用；不会覆盖或删除其他作者的类别与标注。

Windows x64。0.7.0 / 0.7.1 项目、身份与私人编辑格式不变，无需重新导入。更新前保存并同步，再关闭程序。
